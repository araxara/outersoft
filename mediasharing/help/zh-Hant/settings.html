設定參考

在 App 中點一下任一欄位旁的 (i) 可看到相同的說明。大多數欄位都可保持預設值。

連線到何處

  • 連線名稱——顯示在側邊欄中的標籤，僅供你參考。它不影響連線的運作方式。
  • 遠端登入（使用者@主機）——遠端 Mac 的 SSH 使用者名稱和主機（或動態 DNS 名稱）， 例如 alex@myhome.example.com——與你給 ssh 的相同的 user@host。
  • 遠端 SSH 連接埠——到達遠端 Mac SSH 伺服器所用的 TCP 連接埠。通常不是 22，因為路由器常把一個自訂的外部連接埠 （如 22022）轉送到家庭網路內 Mac 的 SSH 連接埠。

連接埠

  • 本機轉送連接埠——這台 Mac 上的一個空閒連接埠。遠端資料庫的「家庭共享」連接埠會被導入這裡， 因此查看該連接埠 localhost 的 App 便可到達遠端資料庫。
  • 遠端媒體共享連接埠——「家庭共享」在遠端 Mac 那頭聆聽的連接埠——通常是 3689，標準的 DAAP /「家庭共享」連接埠。 僅在設定不尋常時才更改它。

通道行為

  • SSH 控制通訊端路徑——ssh 背景控制通訊端的本機檔案路徑， 它讓 App 能乾淨地關閉通道（ssh -O exit），而不是強行終止程序。
  • Server Alive Interval——ssh 每隔多少秒向遠端發送一次 ping， 以便穿過路由器和防火牆保持通道存活，並在它中斷時迅速察覺。
  • 流量輪詢間隔——流量面板每隔多少秒重新取樣 nettop。 每次取樣需要幾秒；更短的間隔只會讓取樣一個接一個地進行。
  • SSH 壓縮——開啟 ssh 的壓縮（-C）。 它以少量 CPU 換取更小的資料流，在緩慢或高延遲的家庭連線上可以明顯地使播放更流暢。保持開啟即可。
