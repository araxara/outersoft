在家中的 Mac 上

在你想存取其資料庫的那台 Mac 上做一次即可。

開啟資料庫的共享

  • 在 Apple TV 或 音樂 App 中，登入你的 Apple 帳號並開啟家庭共享 （較舊的系統稱之為媒體共享）。
  • 讓那台 Mac 保持喚醒，或將其設為睡眠時允許網路存取，這樣你連線時它才能回應。

開啟遠端登入（SSH）

  1. 在遠端 Mac 上，打開 系統設定 › 一般 › 共享。
  2. 開啟 遠端登入。記下獲准登入的使用者帳號。
提示：設定一個 SSH 密鑰，就不必每次都輸入密碼。將這台 Mac 的公鑰複製到遠端 Mac （ssh-copy-id user@host）。Media Sharing GUI 仍會接受密碼作為後備——請參閱 SSH 密鑰與密碼。

使其可從外部存取

  • 連接埠轉送：在家中的路由器上，把一個外部連接埠轉送到遠端 Mac 的 SSH 連接埠（22）。許多人會轉送一個不常見的外部連接埠， 例如 22022，以避免雜訊——你在 遠端 SSH 連接埠 中填寫的就是那個外部連接埠。
  • 跟隨家庭 IP 的名稱：家庭網路位址會變化，所以一個跟隨它的動態 DNS 名稱 （如 myhome.example.com）能讓你不必追逐數字。

一旦遠端登入能從外部運作（在終端機中用 ssh user@host -p PORT 測試），Media Sharing GUI 就能使用它。
