配置参考

在 App 中点按任一字段旁的 (i) 可看到相同的说明。大多数字段都可保持默认值。

连接到何处

  • 连接名称——显示在边栏中的标签，仅供你参考。它不影响连接的工作方式。
  • 远程登录（用户@主机）——远程 Mac 的 SSH 用户名和主机（或动态 DNS 名称）， 例如 alex@myhome.example.com——与你给 ssh 的相同的 user@host。
  • 远程 SSH 端口——到达远程 Mac SSH 服务器所用的 TCP 端口。通常不是 22，因为路由器常把一个自定义的外部端口 （如 22022）转发到家庭网络内 Mac 的 SSH 端口。

端口

  • 本地转发端口——这台 Mac 上的一个空闲端口。远程资料库的“家庭共享”端口会被隧道到这里， 因此查看该端口 localhost 的 App 便可到达远程资料库。
  • 远程媒体共享端口——“家庭共享”在远程 Mac 那头监听的端口——通常是 3689，标准的 DAAP /“家庭共享”端口。 仅在设置不寻常时才更改它。

隧道行为

  • SSH 控制套接字路径——ssh 后台控制套接字的本地文件路径， 它让 App 能干净地关闭隧道（ssh -O exit），而不是强行杀死进程。
  • Server Alive Interval——ssh 每隔多少秒向远端发送一次 ping， 以便穿过路由器和防火墙保持隧道存活，并在它中断时迅速察觉。
  • 流量轮询间隔——流量面板每隔多少秒重新采样 nettop。 每次采样需要几秒；更短的间隔只会让采样一个接一个地进行。
  • SSH 压缩——开启 ssh 的压缩（-C）。 它以少量 CPU 换取更小的数据流，在缓慢或高延迟的家庭连接上可以明显地使播放更流畅。保持开启即可。
