在家里的 Mac 上

在你想访问其资料库的那台 Mac 上做一次即可。

开启资料库的共享

  • 在 Apple TV 或 音乐 App 中，登录你的 Apple 账户并开启家庭共享 （较旧的系统称之为媒体共享）。
  • 让那台 Mac 保持唤醒，或将其设为睡眠时允许网络访问，这样你连接时它才能应答。

开启远程登录（SSH）

  1. 在远程 Mac 上，打开 系统设置 › 通用 › 共享。
  2. 开启 远程登录。记下获准登录的用户账户。
提示：设置一个 SSH 密钥，就不必每次都输入密码。将这台 Mac 的公钥复制到远程 Mac （ssh-copy-id user@host）。Media Sharing GUI 仍会接受密码作为后备——请参阅 SSH 密钥与密码。

使其可从外部访问

  • 端口转发：在家中的路由器上，把一个外部端口转发到远程 Mac 的 SSH 端口（22）。许多人会转发一个不常见的外部端口， 例如 22022，以避免噪音——你在 远程 SSH 端口 中填写的就是那个外部端口。
  • 跟随家庭 IP 的名称：家庭网络地址会变化，所以一个跟随它的动态 DNS 名称 （如 myhome.example.com）能让你不必追逐数字。

一旦远程登录能从外部工作（在终端中用 ssh user@host -p PORT 测试），Media Sharing GUI 就能使用它。
