If it won't connect

Read the Log box — the line starting ERROR: usually says what's wrong. Here are the common ones.

It can't log in

  • Authentication keeps failing. Check Remote login and Remote SSH port, and that Remote Login is on at the far end. Try the same from Terminal: ssh user@host -p PORT. If you changed the remote password, click Forget Saved Password and enter the new one.
  • The tunnel dies right after connecting. The remote Mac may be asleep — waking only briefly for each connection — or dropping connections. Set it to stay awake, or to allow network access on sleep.

It connects, but finds no library

  • “No _home-sharing record found.” Home Sharing (or Media Sharing) isn't turned on, or no Apple TV / Music / iTunes library is online on that network. Turn Home Sharing on, signed in with your Apple Account, and make sure a library there is awake. See On the Mac at home.
  • Libraries were found but none could be published. The Log lists a reason per library; usually a local port was unavailable. Try again, or change the Local forwarded port.

When all else fails

Stopping and starting the connection (or Restart from its sidebar menu) clears most transient trouble. The log file captures the detail if you want to look closer.
