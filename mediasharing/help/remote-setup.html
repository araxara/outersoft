Media Sharing GUI Help › Getting Started

On the Mac at home

Do this once on the Mac whose library you want to reach.

Turn on the library's sharing

  • In the Apple TV app or Music, turn on Home Sharing (older systems call it Media Sharing), signed in with your Apple Account.
  • Leave that Mac awake, or set it to allow network access while asleep, so it can answer when you connect.

Turn on Remote Login (SSH)

  1. On the remote Mac, open System Settings › General › Sharing.
  2. Turn on Remote Login. Note the user account that's allowed to log in.
Tip: Set up an SSH key so you don't need a password every time. Copy this Mac's public key to the remote one (ssh-copy-id user@host). Media Sharing GUI still accepts a password as a fallback — see SSH keys and passwords.

Make it reachable from outside

  • Port forwarding: on the home router, forward an external port to the remote Mac's SSH port (22). Many people forward an unusual outside port, such as 22022, to avoid noise — that outside port is what you put in Remote SSH port.
  • A name that follows the home IP: home internet addresses change, so a dynamic-DNS name (like myhome.example.com) that tracks it saves you from chasing numbers.

Once Remote Login works from outside — test with ssh user@host -p PORT in Terminal — Media Sharing GUI can use it.
