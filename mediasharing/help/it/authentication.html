Chiavi e password SSH

L'accesso con chiave è il migliore; una password salvata è la riserva.

Con una chiave SSH

Se il Mac remoto si fida già della chiave SSH di questo Mac, Media Sharing GUI accede in silenzio: niente da digitare. Configurare una chiave una volta (ssh-copy-id user@host) è il modo più scorrevole di usare l'app. Vedi Sul Mac a casa.

Con una password

Se l'accesso con chiave fallisce, la situazione passa a PASSWORD RICHIESTA:

  1. Digita la password dell'account nel riquadro Autenticazione SSH e premi Invia.
  2. Una volta che funziona, la password viene salvata nel portachiavi di questo Mac, così non ti viene più richiesta.

Puoi anche digitare una password nella Configurazione in anticipo; viene usata solo se l'accesso con chiave fallisce, e anch'essa passa nel portachiavi al primo successo.

Dimenticare una password salvata

Fai clic su Dimentica password salvata per rimuovere la voce del portachiavi dell'accesso corrente — per esempio dopo aver cambiato la password sul Mac remoto. La connessione successiva la richiederà di nuovo.
