Sul Mac a casa

Fai questo una volta sul Mac la cui libreria vuoi raggiungere.

Attivare la condivisione della libreria

  • Nell'app Apple TV o Musica, attiva la Condivisione in casa (i sistemi più vecchi la chiamano Media Sharing), con il tuo account Apple collegato.
  • Lascia quel Mac sveglio, o impostalo per consentire l'accesso alla rete durante lo stop, così può rispondere quando ti connetti.

Attivare il login remoto (SSH)

  1. Sul Mac remoto, apri Impostazioni di Sistema › Generali › Condivisione.
  2. Attiva Login remoto. Annota l'account utente a cui è consentito l'accesso.
Consiglio: Configura una chiave SSH per non aver bisogno di una password ogni volta. Copia la chiave pubblica di questo Mac su quello remoto (ssh-copy-id user@host). Media Sharing GUI accetta comunque una password come riserva: vedi Chiavi e password SSH.

Renderlo raggiungibile dall'esterno

  • Inoltro delle porte: sul router di casa, inoltra una porta esterna alla porta SSH del Mac remoto (22). Molti inoltrano una porta esterna insolita, come 22022, per evitare rumore: quella porta esterna è ciò che inserisci in Porta SSH remota.
  • Un nome che segue l'IP di casa: gli indirizzi internet domestici cambiano, quindi un nome DNS dinamico (come myhome.example.com) che lo segue ti evita di rincorrere i numeri.

Una volta che il login remoto funziona dall'esterno — provalo con ssh user@host -p PORT nel Terminale — Media Sharing GUI può usarlo.
