What Media Sharing GUI reads, changes and keeps

The app connects only this Mac to your own remote Mac. Nothing goes anywhere else.

On this Mac

  • Keeps: your connection settings, and any SSH password you enter — the password in the macOS Keychain, nowhere else. Forget Saved Password removes it.
  • Writes: a log file of what each connection did (see Traffic and the log). You can reveal or delete it at any time.
  • Publishes: the remote library on this Mac's own network over Bonjour, so the Apple TV and Music apps can see it — only while a connection is running.

Over the network

  • Connects only to the remote Mac you name, by SSH, using the built-in ssh tool. Streaming travels encrypted inside that tunnel.
  • No third parties. There's no cloud service, no account to create, and nothing is sent to Outersoft or anyone else.
