Reconnecting and sleep

A home connection isn't always steady. The app rides out the bumps for you.

Staying alive

While connected, ssh pings the remote end every Server Alive Interval seconds (see Configuration reference). That keeps routers and firewalls from dropping an idle tunnel and lets the app notice quickly when a connection really has died.

Automatic reconnect

If the connection drops, the state turns to RECONNECTING and Media Sharing GUI retries on its own, waiting a little longer between attempts, logging each one. Press Stop to call off the retries.

After the Mac sleeps

When this Mac wakes from sleep, the app checks whether the tunnel survived. If it did, it carries on; if not, it does a full reset — the same as Stop then Start — and brings the library back by itself.
