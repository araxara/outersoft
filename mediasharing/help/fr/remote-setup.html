Aide de Media Sharing GUI › Premiers pas

Sur le Mac à la maison

Faites ceci une fois sur le Mac dont vous voulez joindre la bibliothèque.

Activer le partage de la bibliothèque

  • Dans l'app Apple TV ou Musique, activez le partage à domicile (les anciens systèmes l'appellent Media Sharing), connecté avec votre identifiant Apple.
  • Laissez ce Mac éveillé, ou réglez-le pour autoriser l'accès réseau en veille, afin qu'il puisse répondre quand vous vous connectez.

Activer la connexion à distance (SSH)

  1. Sur le Mac distant, ouvrez Réglages Système › Général › Partage.
  2. Activez Connexion à distance. Notez le compte utilisateur autorisé à se connecter.
Astuce : Configurez une clé SSH pour ne pas avoir besoin d'un mot de passe à chaque fois. Copiez la clé publique de ce Mac sur le Mac distant (ssh-copy-id user@host). Media Sharing GUI accepte quand même un mot de passe en secours — voir Clés et mots de passe SSH.

Le rendre joignable depuis l'extérieur

  • Redirection de port : sur le routeur domestique, redirigez un port externe vers le port SSH du Mac distant (22). Beaucoup redirigent un port externe inhabituel, comme 22022, pour éviter le bruit — ce port externe est celui que vous indiquez dans Port SSH distant.
  • Un nom qui suit l'IP domestique : les adresses Internet domestiques changent, donc un nom DNS dynamique (comme myhome.example.com) qui la suit vous évite de courir après les numéros.

Une fois que la connexion à distance fonctionne depuis l'extérieur — testez avec ssh user@host -p PORT dans Terminal — Media Sharing GUI peut l'utiliser.
