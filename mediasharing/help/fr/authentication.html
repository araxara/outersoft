Clés et mots de passe SSH

La connexion par clé est préférable ; un mot de passe enregistré est le secours.

Avec une clé SSH

Si le Mac distant fait déjà confiance à la clé SSH de ce Mac, Media Sharing GUI se connecte en silence — rien à saisir. Configurer une clé une fois (ssh-copy-id user@host) est la façon la plus fluide d'utiliser l'app. Voir Sur le Mac à la maison.

Avec un mot de passe

Si la connexion par clé échoue, le statut passe à MOT DE PASSE REQUIS :

  1. Saisissez le mot de passe du compte dans la zone Authentification SSH et appuyez sur Envoyer.
  2. Une fois qu'il fonctionne, le mot de passe est enregistré dans le trousseau de ce Mac, pour ne plus vous être demandé.

Vous pouvez aussi saisir un mot de passe dans la Configuration à l'avance ; il n'est utilisé que si la connexion par clé échoue, et lui aussi passe dans le trousseau au premier succès.

Oublier un mot de passe enregistré

Cliquez sur Oublier le mot de passe enregistré pour retirer l'entrée du trousseau de la connexion actuelle — par exemple après avoir changé le mot de passe sur le Mac distant. La prochaine connexion le redemandera.
