Référence de la configuration

Cliquez sur le (i) à côté d'un champ dans l'app pour les mêmes notes. La plupart des champs peuvent rester à leurs valeurs par défaut.

Où se connecter

  • Nom de la connexion — une étiquette affichée dans la barre latérale, pour votre repère seulement. Elle n'influe pas sur le fonctionnement de la connexion.
  • Identifiant distant (utilisateur@hôte) — le nom d'utilisateur SSH et l'hôte (ou nom DNS dynamique) du Mac distant, p. ex. alex@myhome.example.com — le même user@host que vous donneriez à ssh.
  • Port SSH distant — le port TCP sur lequel le serveur SSH du Mac distant est joint. Souvent pas 22, car les routeurs redirigent fréquemment un port externe personnalisé (comme 22022) vers le port SSH du Mac dans le réseau domestique.

Ports

  • Port local redirigé — un port libre sur ce Mac. Le port de partage à domicile de la bibliothèque distante est tunnelisé jusqu'ici, de sorte qu'une app regardant localhost sur ce port atteint la bibliothèque distante.
  • Port Media Sharing distant — le port sur lequel le partage à domicile écoute là-bas, sur le Mac distant — normalement 3689, le port DAAP / partage à domicile standard. Ne le modifiez que pour une configuration inhabituelle.

Comportement du tunnel

  • Chemin du socket de contrôle SSH — un chemin de fichier local pour le socket de contrôle d'arrière-plan de ssh, qui permet à l'app de fermer le tunnel proprement (ssh -O exit) au lieu de tuer le processus.
  • Server Alive Interval — à quelle fréquence, en secondes, ssh envoie un ping à l'extrémité distante pour maintenir le tunnel à travers routeurs et pare-feu et remarquer vite s'il meurt.
  • Intervalle d'interrogation du trafic — à quelle fréquence, en secondes, le panneau Trafic ré-échantillonne nettop. Chaque échantillon prend quelques secondes ; un intervalle plus court les enchaîne simplement.
  • Compression SSH — active la compression de ssh (-C). Elle échange un peu de CPU contre un flux de données plus petit, ce qui peut nettement lisser la lecture sur une connexion domestique lente ou à forte latence. On peut la laisser activée sans souci.
