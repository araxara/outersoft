Choosing which libraries to publish

One remote network can share more than one library. You choose which appear here.

When the connection reaches QUERYING, Media Sharing GUI lists every Home Sharing library it finds on the remote Mac's network in the Libraries box — one row each. Until it finds any, the box reads (none discovered yet).

Show or hide a library

  • Turn a row's checkbox on to publish that library here: it's forwarded through the tunnel and advertised over Bonjour, and shows up in the Apple TV or Music app.
  • Turn it off to stop publishing just that one; the others stay.
  • Each published library gets its own local forwarded port. The small detail text on the row shows that port and the library's Home Sharing id, for reference.
Note: A library has to be online on the remote network to be found. If a Mac or Apple TV there is asleep, its library may not appear until it wakes.
