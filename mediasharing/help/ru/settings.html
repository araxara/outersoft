Справочник по конфигурации

Нажмите (i) рядом с любым полем в приложении, чтобы увидеть те же заметки. Большинство полей можно оставить по умолчанию.

Куда подключаться

  • Название подключения — метка в боковом меню, только для вашей справки. На работу подключения она не влияет.
  • Удалённый вход (пользователь@хост) — имя пользователя SSH и хост (или имя динамического DNS) удалённого Mac, напр. alex@myhome.example.com — тот же user@host, что вы дали бы ssh.
  • Удалённый порт SSH — TCP-порт, по которому достигается SSH-сервер удалённого Mac. Часто не 22, потому что роутеры обычно пробрасывают нестандартный внешний порт (как 22022) на порт SSH Mac внутри домашней сети.

Порты

  • Локальный перенаправляемый порт — свободный порт на этом Mac. Порт Домашней коллекции удалённой библиотеки туннелируется сюда, так что приложение, смотрящее на localhost по этому порту, достигает удалённой библиотеки.
  • Удалённый порт Media Sharing — порт, который Домашняя коллекция слушает там, на удалённом Mac — обычно 3689, стандартный порт DAAP / Домашней коллекции. Меняйте его только для необычной настройки.

Поведение туннеля

  • Путь к управляющему сокету SSH — локальный путь к файлу для фонового управляющего сокета ssh, который позволяет приложению аккуратно закрыть туннель (ssh -O exit) вместо того, чтобы убивать процесс.
  • Server Alive Interval — как часто, в секундах, ssh пингует удалённую сторону, чтобы поддерживать туннель через роутеры и файрволы и быстро замечать, если он умер.
  • Интервал опроса трафика — как часто, в секундах, панель трафика пересчитывает nettop. Каждый замер длится несколько секунд; более короткий интервал просто запускает их один за другим.
  • Сжатие SSH — включает сжатие ssh (-C). Оно обменивает немного ЦП на меньший поток данных, что может заметно сгладить воспроизведение по медленному или высоколатентному домашнему соединению. Можно спокойно оставить включённым.
