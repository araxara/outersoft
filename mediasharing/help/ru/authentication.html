Ключи и пароли SSH

Вход по ключу — лучший вариант; сохранённый пароль — запасной.

С ключом SSH

Если удалённый Mac уже доверяет ключу SSH этого Mac, Media Sharing GUI входит без лишних слов — ничего вводить не нужно. Один раз настроить ключ (ssh-copy-id user@host) — самый гладкий способ пользоваться приложением. См. На Mac дома.

С паролем

Если вход по ключу не удаётся, состояние меняется на НУЖЕН ПАРОЛЬ:

  1. Введите пароль учётной записи в блоке Аутентификация SSH и нажмите Отправить.
  2. Как только он сработает, пароль сохраняется в Связке ключей этого Mac, чтобы больше не спрашивать.

Можно также заранее ввести пароль в Конфигурация; он используется только если вход по ключу не удаётся, и тоже перемещается в Связку ключей при первом успехе.

Забыть сохранённый пароль

Нажмите Забыть сохранённый пароль, чтобы удалить запись Связки ключей для текущего входа — например, после смены пароля на удалённом Mac. Следующее подключение снова спросит его.
