Αναφορά διαμόρφωσης

Κάντε κλικ στο (i) δίπλα σε οποιοδήποτε πεδίο στην εφαρμογή για τις ίδιες σημειώσεις. Τα περισσότερα πεδία μπορούν να μείνουν στις προεπιλογές τους.

Πού να συνδεθείτε

  • Όνομα σύνδεσης — μια ετικέτα που εμφανίζεται στην πλαϊνή στήλη, μόνο για δική σας αναφορά. Δεν επηρεάζει τον τρόπο λειτουργίας της σύνδεσης.
  • Απομακρυσμένη σύνδεση (user@host) — το όνομα χρήστη SSH και ο κεντρικός υπολογιστής (ή όνομα δυναμικού DNS) του απομακρυσμένου Mac, π.χ. alex@myhome.example.com — το ίδιο user@host που θα δίνατε στο ssh.
  • Απομακρυσμένη θύρα SSH — η θύρα TCP στην οποία φτάνει ο διακομιστής SSH του απομακρυσμένου Mac. Συχνά όχι 22, επειδή οι δρομολογητές συνήθως προωθούν μια προσαρμοσμένη εξωτερική θύρα (όπως 22022) στη θύρα SSH του Mac μέσα στο οικιακό δίκτυο.

Θύρες

  • Τοπική προωθημένη θύρα — μια ελεύθερη θύρα σε αυτόν τον Mac. Η θύρα Κοινής χρήσης στο σπίτι της απομακρυσμένης βιβλιοθήκης διοχετεύεται εδώ, ώστε μια εφαρμογή που κοιτά το localhost σε αυτήν τη θύρα να φτάνει την απομακρυσμένη βιβλιοθήκη.
  • Απομακρυσμένη θύρα Media Sharing — η θύρα στην οποία ακούει η Κοινή χρήση στο σπίτι εκεί, στον απομακρυσμένο Mac — κανονικά 3689, η τυπική θύρα DAAP / Κοινής χρήσης στο σπίτι. Αλλάξτε την μόνο για μια ασυνήθιστη διαμόρφωση.

Συμπεριφορά σήραγγας

  • Διαδρομή υποδοχής ελέγχου SSH — μια τοπική διαδρομή αρχείου για την υποδοχή ελέγχου παρασκηνίου του ssh, που επιτρέπει στην εφαρμογή να κλείνει τη σήραγγα καθαρά (ssh -O exit) αντί να σκοτώνει τη διεργασία.
  • Server Alive Interval — πόσο συχνά, σε δευτερόλεπτα, το ssh κάνει ping στο απομακρυσμένο άκρο για να κρατά τη σήραγγα μέσα από δρομολογητές και τείχη προστασίας και να αντιλαμβάνεται γρήγορα αν πεθάνει.
  • Διάστημα δειγματοληψίας κίνησης — πόσο συχνά, σε δευτερόλεπτα, το πλαίσιο Κίνησης ξανασαμπλάρει το nettop. Κάθε δείγμα παίρνει μερικά δευτερόλεπτα· ένα μικρότερο διάστημα απλώς τα εκτελεί το ένα μετά το άλλο.
  • Συμπίεση SSH — ενεργοποιεί τη συμπίεση του ssh (-C). Ανταλλάσσει λίγο CPU με μια μικρότερη ροή δεδομένων, κάτι που μπορεί να ομαλοποιήσει αισθητά την αναπαραγωγή σε μια αργή ή υψηλής καθυστέρησης οικιακή σύνδεση. Μπορείτε να την αφήσετε ενεργή με ασφάλεια.
