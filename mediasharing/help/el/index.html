Βοήθεια Media Sharing GUI

Κάντε μια βιβλιοθήκη Κοινής χρήσης στο σπίτι σε έναν Mac κάπου αλλού — στο σπίτι, ας πούμε — να εμφανίζεται στο δικό του δίκτυο αυτού του Mac, για περιήγηση και αναπαραγωγή μέσω μιας ασφαλούς σήραγγας SSH.

Έναρξη

  • Πώς λειτουργεί το Media Sharing GUI
  • Στον Mac στο σπίτι
  • Ρύθμιση και έναρξη μιας σύνδεσης

Χρήση

  • Κατάσταση
  • Επιλογή ποιες βιβλιοθήκες θα δημοσιευτούν
  • Κλειδιά και κωδικοί SSH
  • Κίνηση και αρχείο καταγραφής
  • Πολλές συνδέσεις ταυτόχρονα
  • Γραμμή μενού, σύνδεση και εμφάνιση

Αναφορά

  • Αναφορά διαμόρφωσης
  • Επανασύνδεση και ύπνος
  • Αν δεν συνδέεται
  • Τι διαβάζει, αλλάζει και κρατά το Media Sharing GUI
