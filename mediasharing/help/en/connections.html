Media Sharing GUI Help › Using It

Several connections at once

Set up as many remote Macs as you like and switch between them in the sidebar.

The sidebar

  • Click a connection to select it; its configuration and status fill the main area.
  • Use + to add a new connection (also File › New Connection), and – to remove the selected one. Removing a connection that's still active closes its tunnel first — the app asks before it does.

Run several, or open one on its own

  • Each connection starts and stops independently, so you can have more than one library published at the same time.
  • Control-click a connection for Open in Separate Window, to watch one on its own, and for Restart, which stops and starts it in one step.
