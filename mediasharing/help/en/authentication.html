SSH keys and passwords

Key-based login is best; a saved password is the fallback.

With an SSH key

If the remote Mac already trusts this Mac's SSH key, Media Sharing GUI logs in silently — nothing to type. Setting up a key once (ssh-copy-id user@host) is the smoothest way to use the app. See On the Mac at home.

With a password

If key login fails, the state turns to NEEDS PASSWORD:

  1. Type the account's password in the SSH Authentication box and press Submit.
  2. Once it works, the password is saved to this Mac's Keychain, so you won't be asked again.

You can also type a password into Configuration ahead of time; it's only ever used if key login fails, and it, too, is moved to the Keychain on first success.

Forget a saved password

Click Forget Saved Password to remove the Keychain entry for the current login — for example after you change the password on the remote Mac. The next connection will ask for it again.
