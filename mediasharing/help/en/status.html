Status and state

The Status box is where you Start and Stop, and watch what's happening.

What the state means

StateWhat's happening
IDLENot connected. Press Start to begin.
CONNECTINGOpening the SSH tunnel to the remote Mac.
NEEDS PASSWORDKey login didn't work; enter the password in SSH Authentication.
QUERYINGAsking the remote Mac which Home Sharing library it advertises.
REGISTERINGPublishing that library here over Bonjour.
RUNNINGLive. The library is available in the Apple TV / Music app.
RECONNECTINGThe connection dropped; it's retrying on its own.
STOPPINGClosing the tunnel and removing the local advertisement.
ERRORSomething went wrong; the Log says what. See If it won't connect.

The other rows

  • Tunnel PID — the process id of the background ssh tunnel, used to sample traffic and to close it cleanly.
  • Uptime — how long the current connection has been up.

The buttons at the bottom change with the state: Start when idle, Stop while connected, and Cancel while it's still connecting.
