Set up and start a connection

Fill in where the library lives, then press Start.

Fill in the connection

Click the Configuration (click to edit) box and set at least:

  • Connection name — a label for your own reference, shown in the sidebar.
  • Remote login (user@host) — the same user@host you'd give ssh, for example alex@myhome.example.com.
  • Remote SSH port — the port your router forwards to the remote Mac's SSH (often not 22).

The other fields have sensible defaults; click the (i) beside any of them, or see the Configuration reference, for what each one does.

Press Start

  1. Click Start at the bottom of the window.
  2. If key-based login doesn't go through, the state turns to NEEDS PASSWORD: type the account's password in SSH Authentication and press Submit. It's saved to your Keychain so you're not asked again.
  3. The app opens the tunnel, asks the remote Mac what it's sharing, and publishes it here. When the state reads RUNNING, the library is live.

See it in the Apple TV or Music app

Open the Apple TV app or Music on this Mac. The remote library appears in the source list, the same as a computer on your own network would. If several libraries were found, pick which ones to show in the Libraries box.

Click Stop to close the tunnel and stop publishing. Media Sharing GUI remembers the connection for next time.
