Chaves e senhas SSH

O login por chave é o melhor; uma senha salva é a reserva.

Com uma chave SSH

Se o Mac remoto já confia na chave SSH deste Mac, o Media Sharing GUI entra em silêncio — nada a digitar. Configurar uma chave uma vez (ssh-copy-id user@host) é a forma mais tranquila de usar o app. Consulte No Mac de casa.

Com uma senha

Se o login por chave falhar, a situação muda para SENHA NECESSÁRIA:

  1. Digite a senha da conta na área Autenticação SSH e aperte Enviar.
  2. Assim que funciona, a senha é salva no chaveiro deste Mac, para não ser pedida de novo.

Você também pode digitar uma senha na Configuração com antecedência; ela só é usada se o login por chave falhar, e também vai para o chaveiro no primeiro sucesso.

Esquecer uma senha salva

Clique em Esquecer senha salva para remover a entrada do chaveiro do login atual — por exemplo, depois de mudar a senha no Mac remoto. A próxima conexão vai pedi-la de novo.
