Escolher quais bibliotecas publicar

Uma rede remota pode compartilhar mais de uma biblioteca. Você escolhe quais aparecem aqui.

Quando a conexão chega a CONSULTANDO, o Media Sharing GUI lista cada biblioteca de Compartilhamento Familiar que encontra na rede do Mac remoto na área Bibliotecas — uma linha para cada. Até encontrar alguma, a área mostra (nenhuma descoberta ainda).

Mostrar ou ocultar uma biblioteca

  • Marque a caixa de uma linha para ativar a publicação dessa biblioteca aqui: ela é redirecionada pelo túnel e anunciada via Bonjour, e aparece no app Apple TV ou Música.
  • Desmarque-a para parar de publicar só essa; as outras permanecem.
  • Cada biblioteca publicada ganha sua própria porta local redirecionada. O pequeno texto de detalhe na linha mostra essa porta e o identificador de Compartilhamento Familiar da biblioteca, para referência.
Nota: Uma biblioteca precisa estar on-line na rede remota para ser encontrada. Se um Mac ou Apple TV lá estiver em repouso, sua biblioteca pode não aparecer até acordar.
