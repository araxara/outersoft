Referência da configuração

Clique no (i) ao lado de qualquer campo no app para as mesmas notas. A maioria dos campos pode ficar nos valores padrão.

Onde conectar

  • Nome da conexão — um rótulo exibido na barra lateral, só para sua referência. Não afeta como a conexão funciona.
  • Login remoto (usuário@host) — o nome de usuário SSH e o host (ou nome de DNS dinâmico) do Mac remoto, p. ex. alex@myhome.example.com — o mesmo user@host que você daria ao ssh.
  • Porta SSH remota — a porta TCP em que o servidor SSH do Mac remoto é alcançado. Muitas vezes não é 22, porque os roteadores costumam redirecionar uma porta externa personalizada (como 22022) para a porta SSH do Mac dentro da rede de casa.

Portas

  • Porta local redirecionada — uma porta livre neste Mac. A porta de Compartilhamento Familiar da biblioteca remota é tunelada até aqui, de modo que um app que olha para localhost nesta porta alcança a biblioteca remota.
  • Porta remota do Media Sharing — a porta em que o Compartilhamento Familiar escuta lá, no Mac remoto — normalmente 3689, a porta DAAP / Compartilhamento Familiar padrão. Mude-a apenas para uma configuração incomum.

Comportamento do túnel

  • Caminho do socket de controle SSH — um caminho de arquivo local para o socket de controle em segundo plano do ssh, que permite ao app fechar o túnel de forma limpa (ssh -O exit) em vez de matar o processo.
  • Server Alive Interval — com que frequência, em segundos, o ssh envia um ping à ponta remota para manter o túnel através de roteadores e firewalls e perceber logo se ele morre.
  • Intervalo de consulta de tráfego — com que frequência, em segundos, o painel Tráfego reamostra o nettop. Cada amostra leva alguns segundos; um intervalo mais curto apenas as executa uma após a outra.
  • Compressão SSH — ativa a compressão do ssh (-C). Troca um pouco de CPU por um fluxo de dados menor, o que pode suavizar bastante a reprodução por uma conexão de casa lenta ou de alta latência. Pode deixar ativada sem problema.
