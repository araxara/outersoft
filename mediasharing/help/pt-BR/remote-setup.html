Ajuda do Media Sharing GUI › Primeiros passos

No Mac de casa

Faça isto uma vez no Mac cuja biblioteca você quer alcançar.

Ativar o compartilhamento da biblioteca

  • No app Apple TV ou Música, ative o Compartilhamento Familiar (sistemas mais antigos o chamam de Media Sharing), com sua conta Apple conectada.
  • Deixe esse Mac acordado, ou configure-o para permitir o acesso à rede em repouso, para que ele possa responder quando você se conectar.

Ativar o início de sessão remoto (SSH)

  1. No Mac remoto, abra Ajustes do Sistema › Geral › Compartilhamento.
  2. Ative Início de Sessão Remoto. Anote a conta de usuário com permissão para entrar.
Dica: Configure uma chave SSH para não precisar de senha toda vez. Copie a chave pública deste Mac para o remoto (ssh-copy-id user@host). O Media Sharing GUI ainda aceita uma senha como reserva — consulte Chaves e senhas SSH.

Torná-lo acessível de fora

  • Redirecionamento de porta: no roteador de casa, redirecione uma porta externa para a porta SSH do Mac remoto (22). Muita gente redireciona uma porta externa incomum, como 22022, para evitar ruído — essa porta externa é a que você coloca em Porta SSH remota.
  • Um nome que acompanha o IP de casa: os endereços de internet residenciais mudam, então um nome de DNS dinâmico (como myhome.example.com) que o acompanha poupa você de perseguir números.

Assim que o início de sessão remoto funcionar de fora — teste com ssh user@host -p PORT no Terminal — o Media Sharing GUI pode usá-lo.
