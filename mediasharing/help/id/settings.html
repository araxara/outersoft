Referensi konfigurasi

Klik (i) di sebelah bidang mana pun di app untuk catatan yang sama. Sebagian besar bidang bisa dibiarkan pada nilai bawaannya.

Ke mana menyambung

  • Nama koneksi — label yang ditampilkan di bilah sisi, hanya untuk referensi Anda. Ini tidak memengaruhi cara koneksi bekerja.
  • Login jarak jauh (user@host) — nama pengguna SSH dan host (atau nama DNS dinamis) dari Mac jarak jauh, mis. alex@myhome.example.com — user@host yang sama yang akan Anda berikan ke ssh.
  • Port SSH jarak jauh — port TCP tempat server SSH Mac jarak jauh dijangkau. Sering bukan 22, karena router umumnya meneruskan port eksternal khusus (seperti 22022) ke port SSH Mac di dalam jaringan rumah.

Port

  • Port lokal yang diteruskan — port bebas di Mac ini. Port Berbagi Rumah dari pustaka jarak jauh diterowongkan ke sini, sehingga app yang melihat localhost pada port ini menjangkau pustaka jarak jauh.
  • Port Media Sharing jarak jauh — port tempat Berbagi Rumah mendengarkan di sana, di Mac jarak jauh — biasanya 3689, port DAAP / Berbagi Rumah standar. Ubah hanya untuk pengaturan yang tidak biasa.

Perilaku terowongan

  • Jalur soket kontrol SSH — jalur berkas lokal untuk soket kontrol latar belakang ssh, yang memungkinkan app menutup terowongan dengan rapi (ssh -O exit) alih-alih mematikan proses.
  • Server Alive Interval — seberapa sering, dalam detik, ssh melakukan ping ke ujung jarak jauh untuk menjaga terowongan menembus router dan firewall serta cepat menyadari jika mati.
  • Interval polling traffic — seberapa sering, dalam detik, panel Lalu Lintas menyampel ulang nettop. Setiap sampel memerlukan beberapa detik; interval yang lebih pendek hanya menjalankannya berurutan.
  • Kompresi SSH — menyalakan kompresi ssh (-C). Ia menukar sedikit CPU dengan aliran data yang lebih kecil, yang bisa jelas memuluskan pemutaran di koneksi rumah yang lambat atau berlatensi tinggi. Aman dibiarkan menyala.
