구성 참고

앱에서 각 필드 옆의 (i)를 클릭하면 같은 설명이 나옵니다. 대부분의 필드는 기본값으로 두어도 됩니다.

어디로 연결할지

  • 연결 이름 — 사이드바에 표시되는 이름표로, 참고용일 뿐입니다. 연결 작동 방식에는 영향을 주지 않습니다.
  • 원격 로그인 (user@host) — 원격 Mac의 SSH 사용자 이름과 호스트(또는 동적 DNS 이름), 예: alex@myhome.example.com — ssh에 줄 것과 같은 user@host.
  • 원격 SSH 포트 — 원격 Mac의 SSH 서버에 도달하는 TCP 포트. 라우터가 흔히 사용자 지정 외부 포트(예: 22022)를 집 네트워크 내 Mac의 SSH 포트로 전달하므로 22가 아닌 경우가 많습니다.

포트

  • 로컬 전달 포트 — 이 Mac의 빈 포트. 원격 보관함의 홈 공유 포트가 여기로 터널되므로, 이 포트의 localhost를 보는 앱은 원격 보관함에 도달합니다.
  • 원격 Media Sharing 포트 — 원격 Mac 쪽에서 홈 공유가 수신 대기하는 포트. 보통 3689, 표준 DAAP / 홈 공유 포트입니다. 비정상적인 설정이 아니라면 바꾸지 마십시오.

터널 동작

  • SSH 제어 소켓 경로 — ssh의 백그라운드 제어 소켓을 위한 로컬 파일 경로로, 프로세스를 죽이는 대신 터널을 깔끔하게 닫을 수 있게 합니다(ssh -O exit).
  • Server Alive Interval — ssh가 원격 쪽에 핑을 보내는 빈도(초). 라우터와 방화벽을 넘어 터널을 유지하고, 끊기면 빨리 알아차리기 위한 것입니다.
  • 트래픽 폴링 간격 — 트래픽 패널이 nettop을 다시 표본화하는 빈도(초). 표본 하나에 몇 초가 걸립니다. 더 짧은 간격은 표본을 연달아 실행할 뿐입니다.
  • SSH 압축 — ssh의 압축(-C)을 켭니다. 약간의 CPU를 더 작은 데이터 스트림과 맞바꾸며, 느리거나 지연이 큰 가정 연결에서 재생을 눈에 띄게 매끄럽게 할 수 있습니다. 켜 두어도 안전합니다.
