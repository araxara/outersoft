Media Sharing GUI 도움말 › 시작하기

집에 있는 Mac에서

보관함에 도달하려는 Mac에서 한 번만 하면 됩니다.

보관함 공유 켜기

  • Apple TV 또는 음악 앱에서 Apple 계정으로 로그인한 상태로 홈 공유를 켭니다 (이전 시스템에서는 미디어 공유라고 합니다).
  • 그 Mac을 깨어 있게 두거나, 잠자는 동안 네트워크 접근을 허용하도록 설정하여, 연결할 때 응답할 수 있게 합니다.

원격 로그인(SSH) 켜기

  1. 원격 Mac에서 시스템 설정 › 일반 › 공유를 엽니다.
  2. 원격 로그인을 켭니다. 로그인이 허용된 사용자 계정을 적어 둡니다.
팁: 매번 비밀번호가 필요 없도록 SSH 키를 설정하십시오. 이 Mac의 공개 키를 원격 Mac으로 복사합니다(ssh-copy-id user@host). Media Sharing GUI는 여전히 비밀번호를 대체 수단으로 받아들입니다. SSH 키와 비밀번호를 참조하십시오.

외부에서 도달할 수 있게 하기

  • 포트 포워딩: 집 라우터에서 외부 포트를 원격 Mac의 SSH 포트(22)로 전달합니다. 많은 사람이 잡음을 피하려고 22022 같은 흔치 않은 외부 포트를 전달합니다. 그 외부 포트가 원격 SSH 포트에 입력하는 값입니다.
  • 집 IP를 따라가는 이름: 집 인터넷 주소는 바뀌므로, 이를 따라가는 동적 DNS 이름 (myhome.example.com 등)이 있으면 숫자를 쫓지 않아도 됩니다.

외부에서 원격 로그인이 작동하면(터미널에서 ssh user@host -p PORT로 테스트), Media Sharing GUI가 그것을 사용할 수 있습니다.
