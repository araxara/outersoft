메뉴 막대 항목

Media Sharing GUI는 메뉴 막대에 작은 상태 항목을 놓습니다. 그 도구 설명이 현재 상태를 보여 주며, 메뉴에는 윈도우가 닫혀 있거나 앱이 백그라운드에서 조용히 실행 중일 때 주 윈도우를 다시 불러오는 윈도우 보기가 있습니다.

로그인 시 시작

(앱 메뉴에서) 로그인 시 시작을 켜면 로그인할 때 Media Sharing GUI가 시작됩니다. 처음에는 macOS가 시스템 설정 › 일반 › 로그인 항목에서 승인하도록 요청할 수 있습니다. 그런 경우 로그가 알려 줍니다.

외관과 언어

  • 제목 막대의 외관 버튼은 시스템, 라이트, 다크 사이를 전환합니다.
  • 보기 › 언어는 이 앱에만 언어를 재정의합니다. 시스템은 Mac 자체의 언어 설정을 따른다는 뜻입니다. 변경하면 적용을 위해 앱이 다시 시작됩니다.
