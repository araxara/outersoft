自宅の Mac で

ライブラリに到達したい Mac で、これを一度だけ行います。

ライブラリの共有をオンにする

  • Apple TV App または ミュージック で、Apple アカウントにサインインした状態で ホームシェアリングをオンにします（古いシステムではメディア共有と呼ばれます）。
  • その Mac を起動したままにするか、スリープ中もネットワークアクセスを許可するよう設定します。接続したときに応答できるようにするためです。

リモートログイン（SSH）をオンにする

  1. リモートの Mac で システム設定 › 一般 › 共有 を開きます。
  2. リモートログインをオンにします。ログインを許可するユーザアカウントを控えておきます。
ヒント： 毎回パスワードを入力しなくて済むよう、SSH 鍵を設定しましょう。この Mac の公開鍵をリモートの Mac に コピーします（ssh-copy-id user@host）。Media Sharing GUI はフォールバックとしてパスワードも 受け付けます。SSH の鍵とパスワードを参照。

外部から到達できるようにする

  • ポート転送： 自宅のルーターで、外部ポートをリモートの Mac の SSH ポート（22）に転送します。多くの人はノイズを避けるために 22022 のような珍しい外部ポートを転送します。その外部ポートが リモート SSH ポート に入力する値です。
  • 自宅の IP に追従する名前： 自宅のインターネットアドレスは変わるため、それに追従するダイナミック DNS 名 （myhome.example.com など）があれば、番号を追いかけずに済みます。

外部からリモートログインが機能するようになったら（ターミナルで ssh user@host -p PORT を試します）、 Media Sharing GUI はそれを使えます。
