Media Sharing GUI ヘルプ

別の場所（たとえば自宅）にある Mac 上のホームシェアリングのライブラリを、この Mac 自身のネットワーク上に表示し、安全な SSH トンネル経由で閲覧・再生します。

はじめに

  • Media Sharing GUI のしくみ
  • 自宅の Mac で
  • 接続を設定して開始する

使い方

  • 状況と状態
  • 公開するライブラリを選ぶ
  • SSH の鍵とパスワード
  • トラフィックとログ
  • 複数の接続を同時に
  • メニューバー、ログイン、外観

リファレンス

  • 構成リファレンス
  • 再接続とスリープ
  • 接続できないとき
  • Media Sharing GUI が読み取り・変更・保存するもの
