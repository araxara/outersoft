構成リファレンス

App 内の各フィールド横の (i) をクリックすると同じ説明が出ます。ほとんどのフィールドは 初期値のままで構いません。

接続先

  • 接続名 — サイドバーに表示される名札で、自分のための参照用です。接続の動作には影響しません。
  • リモートログイン (user@host) — リモートの Mac の SSH ユーザ名とホスト（またはダイナミック DNS 名）。 例：alex@myhome.example.com — ssh に渡すのと同じ user@host です。
  • リモート SSH ポート — リモートの Mac の SSH サーバに到達する TCP ポート。 ルーターはしばしばカスタムの外部ポート（22022 など）を自宅ネットワーク内の Mac の SSH ポートに転送するため、 22 でないことが多いです。

ポート

  • ローカル転送ポート — この Mac の空きポート。リモートのライブラリのホームシェアリングポートが ここにトンネルされるため、このポートの localhost を見る App はリモートのライブラリに到達します。
  • リモート Media Sharing ポート — リモートの Mac 側でホームシェアリングが待ち受けるポート。 通常は 3689、標準の DAAP／ホームシェアリングのポートです。特殊な構成でない限り変更しないでください。

トンネルの動作

  • SSH 制御ソケットのパス — ssh のバックグラウンド制御ソケット用のローカルファイルパス。 これにより、プロセスを強制終了せずに、トンネルをきれいに閉じられます（ssh -O exit）。
  • Server Alive Interval — ssh がリモート側に ping を送る頻度（秒）。 ルーターやファイアウォール越しにトンネルを維持し、切れたときに素早く気づくためのものです。
  • トラフィックのポーリング間隔 — トラフィックパネルが nettop を再サンプリングする頻度（秒）。 各サンプリングには数秒かかります。それより短い間隔にしても、続けて実行されるだけです。
  • SSH 圧縮 — ssh の圧縮（-C）をオンにします。 わずかな CPU と引き換えにデータ量を小さくし、遅い、または高遅延の自宅回線での再生を目に見えてなめらかにできます。 オンのままで問題ありません。
