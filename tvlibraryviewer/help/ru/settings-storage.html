Актёры и съёмочная группа сериала ищутся на TVmaze и TMDb при первом открытии его страницы — здесь или на любом устройстве. Сведения о людях загружаются каждый раз, когда вы их открываете, поэтому они всегда актуальны и не хранятся. Нажмите Показать в Finder, чтобы увидеть файл базы данных.

Сведения об актёрах и съёмочной группе: токен TMDb

TVmaze не требует настройки. TMDb (The Movie Database) добавляет режиссёров и сценаристов, актёров, которых нет на TVmaze, и биографии, часто на вашем языке. Для этого нужен собственный токен: TMDb бесплатно выдает его любому, у кого есть учетная запись, для личного некоммерческого использования. TV Library Viewer не поставляется с токеном.

  1. Создайте бесплатную учетную запись на themoviedb.org и войдите.
  2. Нажмите значок своей учетной записи, выберите Settings, затем нажмите API.
  3. Запросите ключ API: выберите Developer, примите условия и опишите использование как личное и некоммерческое (например: «Показ актёров и биографий в моем собственном приложении для медиатеки TV»).
  4. Когда ключ будет готов, скопируйте API Read Access Token (длинный, а не более короткий API Key).
  5. На Mac с медиатекой выберите TV Library Viewer › Настройки, нажмите Хранилище и вставьте токен в поле API Read Access Token TMDb.
  6. Нажмите Проверить. Сообщение «TMDb принимает этот токен» означает, что всё работает.

Токен хранится в Связке ключей Mac. Его использует только Mac с медиатекой; другие ваши устройства получают актёров и сведения от этого Mac. Сериалы, которые уже искали, получат актёров и съёмочную группу из TMDb при следующем открытии их страницы. Если закрыть настройки, не проверив новый токен, он будет проверен в этот момент, и вы получите сообщение, если TMDb его отклонит.

Примечание. Этот продукт использует API TMDB, но не одобрен и не сертифицирован TMDB.

Перевод: ключ Google

Названия и описания серий переводятся на язык каждого устройства на этом Mac бесплатно, с помощью перевода Apple. Он не умеет переводить на греческий, чешский, венгерский, румынский, персидский, урду и бенгальский. Для этих языков добавьте собственный ключ Google Cloud Translation API. Он нужен только Mac с медиатекой, а не устройствам, которые ее просматривают. Первые 500 000 символов каждый месяц бесплатны, и каждый текст переводится только один раз.

  1. Перейдите на console.cloud.google.com и войдите со своим аккаунтом Google.
  2. Создайте проект: нажмите меню проектов вверху, затем New Project и дайте ему имя, например «TV Library Viewer».
  3. Включите оплату: в меню ☰ выберите Billing и привяжите платежный аккаунт. Google требует его даже для бесплатного использования. Для надежности добавьте бюджет, например 1 $, в разделе Budgets & alerts.
  4. Выберите ☰ › APIs & Services › Library, найдите Cloud Translation API и нажмите Enable.
  5. Выберите ☰ › APIs & Services › Credentials, затем Create credentials › API key и скопируйте ключ (он начинается с «AIza»).
  6. Рекомендуется: нажмите имя ключа, в разделе API restrictions выберите Restrict key, отметьте Cloud Translation API и нажмите Save, чтобы ключ работал только для перевода.
  7. На Mac с медиатекой выберите TV Library Viewer › Настройки, нажмите Хранилище, вставьте ключ в поле Ключ Google Cloud Translation API и нажмите Проверить.

Ключ хранится в Связке ключей Mac и используется только для этих семи языков. Не передавайте его другим: все, что переведено с его помощью, оплачивается с вашего аккаунта Google.
