Obsazení a štáb seriálu se vyhledají na TVmaze a TMDb při prvním otevření jeho stránky, zde nebo na libovolném zařízení. Údaje o osobách se načítají při každém jejich otevření, takže nikdy nejsou zastaralé, a neukládají se. Klikněte na Zobrazit ve Finderu a uvidíte soubor databáze.

Podrobnosti o obsazení a štábu: token TMDb

TVmaze nevyžaduje žádné nastavení. TMDb (The Movie Database) přidává režiséry a scenáristy, herce, které TVmaze nemá, a životopisy, často ve vašem jazyce. Potřebuje váš vlastní token: TMDb ho zdarma poskytne každému, kdo má účet, pro osobní, nekomerční použití. TV Library Viewer žádný token nemá.

  1. Vytvořte si bezplatný účet na themoviedb.org a přihlaste se.
  2. Klikněte na ikonu svého účtu, vyberte Settings a pak klikněte na API.
  3. Požádejte o klíč API: vyberte Developer, přijměte podmínky a popište použití jako osobní a nekomerční (například „Show cast and biographies in my own TV library app“).
  4. Až bude klíč připravený, zkopírujte API Read Access Token (ten dlouhý, ne kratší API Key).
  5. Na Macu s knihovnou vyberte TV Library Viewer › Nastavení, klikněte na Úložiště a vložte ho do pole TMDb API Read Access Token.
  6. Klikněte na Otestovat. „TMDb tento token přijímá“ znamená, že funguje.

Token se uchovává v Klíčence Macu. Používá ho jen Mac s knihovnou; vaše další zařízení dostávají obsazení a podrobnosti z tohoto Macu. Seriály, které už byly vyhledány, dostanou obsazení a štáb z TMDb při příštím otevření jejich stránky. Pokud zavřete Nastavení bez otestování nového tokenu, otestuje se v tu chvíli a dozvíte se, pokud ho TMDb odmítne.

Poznámka: Tento produkt používá rozhraní TMDB API, ale není podporován ani certifikován společností TMDB.

Překlad: klíč Google

Názvy a popisy epizod se na tomto Macu zdarma překládají do jazyka každého zařízení pomocí překladu od Applu. Ten neumí překládat do řečtiny, češtiny, maďarštiny, rumunštiny, perštiny, urdštiny ani bengálštiny. Pro tyto jazyky přidejte vlastní klíč Google Cloud Translation API. Potřebuje ho jen Mac s knihovnou, zařízení, která ji sledují, ne. Prvních 500 000 znaků měsíčně je zdarma a každý text se překládá jen jednou.

  1. Přejděte na console.cloud.google.com a přihlaste se svým účtem Google.
  2. Vytvořte projekt: klikněte na nabídku projektů nahoře, pak na New Project a pojmenujte ho třeba „TV Library Viewer“.
  3. Zapněte fakturaci: v nabídce ☰ vyberte Billing a propojte fakturační účet. Google ho vyžaduje i při bezplatném používání. Pro jistotu přidejte rozpočet, třeba 1 $, v části Budgets & alerts.
  4. Vyberte ☰ › APIs & Services › Library, vyhledejte Cloud Translation API a klikněte na Enable.
  5. Vyberte ☰ › APIs & Services › Credentials, pak Create credentials › API key a zkopírujte klíč (začíná na „AIza“).
  6. Doporučeno: klikněte na název klíče, v části API restrictions vyberte Restrict key, zaškrtněte Cloud Translation API a klikněte na Save, aby klíč fungoval jen pro překlad.
  7. Na Macu s knihovnou vyberte TV Library Viewer › Nastavení, klikněte na Úložiště, vložte klíč do pole Klíč Google Cloud Translation API a klikněte na Otestovat.

Klíč je uložen v klíčence Macu a používá se jen pro těchto sedm jazyků. Nikomu ho nedávejte: vše, co se s ním přeloží, se účtuje na váš účet Google.
