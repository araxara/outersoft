স্টোরেজ সেটিংস

TV Library Viewer › সেটিংস বেছে নিন, তারপর স্টোরেজ-এ ক্লিক করুন।

এই Mac-এর TV লাইব্রেরি

TV অ্যাপের লাইব্রেরিতে শো ও পর্বের সংখ্যা, এবং তার ডেটাবেসের আকার। ভিডিও ফাইলগুলো গণনায় ধরা হয় না।

TV Library Viewer ডেটাবেস

এই Mac-এ TV Library Viewer-এর নিজস্ব ডেটাবেস, লাইব্রেরি দেখা প্রতিটি ডিভাইসের সঙ্গে শেয়ার করা।

অংশএতে কী থাকে
শোর তথ্যAppleScript দিয়ে দেওয়া পূর্ণ বিবরণ, এবং প্রতিটি শোর অভিনয়শিল্পী: অভিনেতাদের নাম ও চরিত্র।
অনুবাদঅ্যাপগুলো যে ভাষায় সেট আছে সেই ভাষায় অনূদিত পর্বের শিরোনাম ও বিবরণ।
কাস্ট ও ক্রুপ্রত্যেকের একটি ছোট ছবি, এবং TVmaze ও TMDb-তে তাদের পেজের ঠিকানা।
অ্যাকাউন্ট ও দেখাঅ্যাকাউন্টগুলো, প্রধান অ্যাকাউন্ট ছাড়া প্রতিটি অ্যাকাউন্টের দেখা, এবং অ্যাকাউন্টগুলোর লগ।
ডেটাবেসের কাঠামো ও খালি জায়গাSQLite-এর নিজস্ব রেকর্ড, এবং যে জায়গা এটি আবার ব্যবহার করে।
সাম্প্রতিক পরিবর্তনযে পরিবর্তনগুলো এখনো ডেটাবেসে মেশানো হয়নি। এটি সেই কাজ মাঝে মাঝে করে।

কোনো শোর কাস্ট ও ক্রু প্রথমবার তার পেজ খোলার সময়, এখানে বা যেকোনো ডিভাইসে, TVmaze ও TMDb-তে খোঁজা হয়। মানুষের বিবরণ প্রতিবার খোলার সময় আনা হয়, তাই সেগুলো কখনো পুরোনো হয় না, এবং সংরক্ষণ করা হয় না। ডেটাবেস ফাইলটি দেখতে Finder-এ দেখান-এ ক্লিক করুন।

কাস্ট ও ক্রুর বিবরণ: একটি TMDb টোকেন

TVmaze-এর জন্য কিছুই সেট আপ করতে হয় না। TMDb (The Movie Database) যোগ করে পরিচালক ও চিত্রনাট্যকার, যে অভিনেতারা TVmaze-এ নেই তাদের, এবং জীবনী, প্রায়ই আপনার ভাষায়। এর জন্য আপনার নিজের একটি টোকেন লাগে: TMDb অ্যাকাউন্ট থাকা যে কাউকে ব্যক্তিগত, অবাণিজ্যিক ব্যবহারের জন্য বিনামূল্যে একটি দেয়। TV Library Viewer-এর সঙ্গে কোনো টোকেন আসে না।

  1. themoviedb.org-এ একটি বিনামূল্যের অ্যাকাউন্ট তৈরি করুন, এবং সাইন ইন করুন।
  2. আপনার অ্যাকাউন্ট আইকনে ক্লিক করুন, Settings বেছে নিন, তারপর API-তে ক্লিক করুন।
  3. একটি API কী-এর অনুরোধ করুন: Developer বেছে নিন, শর্তাবলি মেনে নিন, এবং আপনার ব্যবহারকে ব্যক্তিগত ও অবাণিজ্যিক হিসেবে বর্ণনা করুন (যেমন, “Show cast and biographies in my own TV library app”)।
  4. কী প্রস্তুত হলে, API Read Access Token কপি করুন (লম্বাটি, ছোট API Key নয়)।
  5. লাইব্রেরি থাকা Mac-এ, TV Library Viewer › সেটিংস বেছে নিন, স্টোরেজ-এ ক্লিক করুন, এবং সেটি TMDb API Read Access Token-এ পেস্ট করুন।
  6. পরীক্ষা-তে ক্লিক করুন। “TMDb এই টোকেন গ্রহণ করে” মানে এটি কাজ করছে।

টোকেনটি Mac-এর কীচেইনে রাখা হয়। শুধু লাইব্রেরি থাকা Mac এটি ব্যবহার করে; আপনার অন্য ডিভাইসগুলো সেই Mac থেকে অভিনয়শিল্পী ও বিবরণ পায়। আগে খোঁজা শোগুলো TMDb-এর কাস্ট ও ক্রু পায় পরের বার তাদের পেজ খোলার সময়। নতুন টোকেন পরীক্ষা না করে সেটিংস বন্ধ করলে, তখনই সেটি পরীক্ষা হয়, এবং TMDb সেটি প্রত্যাখ্যান করলে আপনাকে জানানো হয়।

দ্রষ্টব্য: এই পণ্যটি TMDB API ব্যবহার করে, তবে TMDB এটিকে অনুমোদন বা প্রত্যয়ন করেনি।

অনুবাদ: একটি Google কী

পর্বের শিরোনাম ও বিবরণ এই Mac-এ Apple-এর অনুবাদ দিয়ে, বিনামূল্যে, প্রতিটি ডিভাইসের ভাষায় অনুবাদ করা হয়। এটি গ্রিক, চেক, হাঙ্গেরীয়, রোমানীয়, ফারসি, উর্দু বা বাংলায় অনুবাদ করতে পারে না। এই ভাষাগুলোর জন্য আপনার নিজের একটি Google Cloud Translation API কী যোগ করুন। শুধু লাইব্রেরি থাকা Mac-এর এটি লাগে; যে ডিভাইসগুলো লাইব্রেরি দেখে সেগুলোর লাগে না। প্রতি মাসে প্রথম ৫,০০,০০০ অক্ষর বিনামূল্যে, এবং প্রতিটি লেখা শুধু একবারই অনুবাদ করা হয়।

  1. console.cloud.google.com-এ যান এবং আপনার Google অ্যাকাউন্ট দিয়ে সাইন ইন করুন।
  2. একটি প্রজেক্ট তৈরি করুন: ওপরের প্রজেক্ট মেনুতে ক্লিক করুন, তারপর New Project-এ, এবং এটিকে একটি নাম দিন, যেমন “TV Library Viewer”।
  3. বিলিং চালু করুন: মেনু ☰-এ Billing বেছে নিন এবং একটি বিলিং অ্যাকাউন্ট যুক্ত করুন। বিনামূল্যে ব্যবহারের জন্যও Google একটি চায়। নিরাপদ থাকতে, Budgets & alerts-এ একটি বাজেট যোগ করুন, যেমন $১।
  4. ☰ › APIs & Services › Library বেছে নিন, Cloud Translation API খুঁজুন, এবং Enable-এ ক্লিক করুন।
  5. ☰ › APIs & Services › Credentials বেছে নিন, তারপর Create credentials › API key, এবং কী কপি করুন (এটি “AIza” দিয়ে শুরু হয়)।
  6. প্রস্তাবিত: কী-এর নামে ক্লিক করুন, API restrictions-এর নিচে Restrict key বেছে নিন, Cloud Translation API-এ টিক দিন, এবং Save-এ ক্লিক করুন, যাতে কী শুধু অনুবাদের জন্য কাজ করে।
  7. লাইব্রেরি থাকা Mac-এ, TV Library Viewer › সেটিংস বেছে নিন, স্টোরেজ-এ ক্লিক করুন, কী-টি Google Cloud Translation API কী-তে পেস্ট করুন, এবং পরীক্ষা-তে ক্লিক করুন।

কী-টি Mac-এর কীচেইনে রাখা হয় এবং শুধু এই সাতটি ভাষার জন্য ব্যবহার করা হয়। এটি কারও সঙ্গে শেয়ার করবেন না: এটি দিয়ে যা কিছু অনুবাদ হয় তার বিল আপনার Google অ্যাকাউন্টে যায়।

ক্যাশ
