جابه‌جایی بین کتابخانه‌ها

Mac، iPad و iPhone. روی ⁨Apple TV⁩: کتابخانه‌ها.

بخش کتابخانه‌های هم‌رسانی‌شده در نوار کناری، کتابخانه‌هایی را که استفاده کرده‌اید فهرست می‌کند. یک علامت تیک کتابخانه‌ای را که اکنون نشان داده می‌شود مشخص می‌کند.

  • برای رفتن به یک کتابخانه روی آن کلیک کنید. روی Mac، کتابخانهٔ این Mac به کتابخانهٔ خود Mac برمی‌گردد.
  • برای تغییر نام… یا فراموش کردن یک کتابخانه، روی آن Control-کلیک کنید (یا لمس کنید و نگه دارید). کتابخانهٔ تغییرنام‌داده نامی را که شما برایش گذاشته‌اید نگه می‌دارد؛ برای استفاده از نام خود Mac، نام را خالی بگذارید.
  • اتصال به کتابخانهٔ هم‌رسانی‌شده… کتابخانهٔ دیگری اضافه می‌کند.

برنامه کتابخانه‌ای را که آخرین بار استفاده کرده‌اید دوباره باز می‌کند.
