TV Library Viewer 数据库

TV Library Viewer 在这台 Mac 上的自有数据库，与每台查看该资料库的设备共享。

部分包含的内容
剧集信息通过 AppleScript 提供的完整描述，以及每个节目的演员：演员的姓名和角色。
翻译已翻译成各 App 所设语言的剧集标题和简介。
演职员每个人的一张小照片，以及其在 TVmaze 和 TMDb 上的页面地址。
账户与观看账户、除主账户外所有账户的观看记录，以及账户的日志。
数据库结构与可用空间SQLite 自身的记录，以及它会重复使用的空间。
最近的更改尚未合并到数据库中的更改。它会不时进行合并。

节目的演职员会在其页面首次打开时（无论在这里还是在任何设备上）从 TVmaze 和 TMDb 查找。人物详情在每次打开时获取，因此永远不会过时，也不会被存储。点按在访达中显示可查看数据库文件。

演职员详情：TMDb 令牌

TVmaze 无需任何设置。TMDb（The Movie Database）会增加导演和编剧、TVmaze 没有的演员以及人物简介，而且常常是你的语言版本。它需要你自己的令牌：TMDb 免费向任何拥有账户的人提供令牌，供个人非商业用途使用。TV Library Viewer 不附带令牌。

  1. 在 themoviedb.org 创建一个免费账户并登录。
  2. 点按你的账户图标，选取Settings，然后点按API。
  3. 申请 API 密钥：选取Developer，接受条款，并将用途描述为个人和非商业用途（例如“在我自己的电视资料库 App 中显示演员和人物简介”）。
  4. 密钥准备好后，拷贝API Read Access Token（较长的那个，而不是较短的 API Key）。
  5. 在存有资料库的 Mac 上，选取TV Library Viewer › 设置，点按储存空间，然后将其粘贴到TMDb API Read Access Token中。
  6. 点按测试。显示“TMDb 接受此令牌。”即表示可以使用。

令牌保存在 Mac 的钥匙串中。只有存有资料库的 Mac 使用它；你的其他设备从那台 Mac 获取演员和详细信息。已经查找过的节目会在下次打开其页面时获得 TMDb 的演职员。如果你在未测试新令牌的情况下关闭设置，届时会对其进行测试，若 TMDb 拒绝，你会收到通知。

注：本产品使用 TMDB API，但未获得 TMDB 的认可或认证。

翻译：Google 密钥

剧集标题和描述会在这台 Mac 上使用 Apple 的翻译功能免费翻译成每台设备的语言。但它无法翻译成希腊语、捷克语、匈牙利语、罗马尼亚语、波斯语、乌尔都语或孟加拉语。对于这些语言，请添加你自己的 Google Cloud Translation API 密钥。只有存有资料库的 Mac 需要密钥；查看资料库的设备不需要。每月前 50 万个字符免费，并且每段文本只会翻译一次。

  1. 前往 console.cloud.google.com，并使用你的 Google 账户登录。
  2. 创建项目：点按顶部的项目菜单，然后点按New Project，并为其命名，例如“TV Library Viewer”。
  3. 开启结算：在菜单 ☰ 中选择Billing，然后关联一个结算账户。即使免费使用，Google 也会要求提供结算账户。为安全起见，请在Budgets & alerts下添加预算，例如 1 美元。
  4. 选择 ☰ › APIs & Services › Library，搜索Cloud Translation API，然后点按Enable。
  5. 选择 ☰ › APIs & Services › Credentials，然后选择Create credentials › API key，并拷贝密钥（以“AIza”开头）。
  6. 建议：点按密钥的名称，在 API restrictions 下选择Restrict key，勾选Cloud Translation API，然后点按Save，这样密钥就只能用于翻译。
  7. 在存有资料库的 Mac 上，选择TV Library Viewer › 设置，点按储存空间，将密钥粘贴到Google Cloud Translation API 密钥中，然后点按测试。

密钥会保存在 Mac 的钥匙串中，并且只用于这七种语言。请勿与他人共享密钥：使用它翻译的任何内容都会计入你的 Google 账户费用。
