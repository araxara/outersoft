File menu

CommandWhat it does
Open Library… ⌘OOpens another TV app library on this Mac: a .tvlibrary package, or the Library.tvdb file in one.
Connect to Shared Library… ⌘KOpens a library another Mac shares: on this network, through SSH or at an address. See Connect to a shared library.
Account…Your account on the shared library you're viewing: its statistics, the devices it's used from, and changing its password.
Sign In with an Account…
Sign In as Another Account…		Signs in to the shared library with an account, so your watching is your own.
Switch LibraryGoes back to This Mac's Library, or to a shared library you've used before.
Refresh Library ⌘RReads the library again. It normally updates by itself, a moment after the TV app saves a change.
