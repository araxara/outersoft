Window and Help menus

Window

The standard commands: minimize, zoom, and bring a window to the front, including the windows of episodes that are playing.

Help

TV Library Viewer Help opens this help. Type in the Help menu's search field to find a menu command or a help topic.

Keep a Log: Records what the player and the connection to the Mac do (the last 400 events), to send if playback or connecting misbehaves. Leave it off otherwise. Copy Log copies the log; Clear Log empties it.
