Switch between libraries

Mac, iPad and iPhone. On the Apple TV: Libraries.

The Shared Libraries section of the sidebar lists the libraries you've used. A check marks the one showing now.

  • Click a library to switch to it. On a Mac, This Mac's Library goes back to the Mac's own.
  • Control-click (or touch and hold) a library to Rename… it, or Forget it. A renamed library keeps your name for it; leave the name empty to use the Mac's own name.
  • Connect to Shared Library… adds another.

The app reopens the library you used last.
