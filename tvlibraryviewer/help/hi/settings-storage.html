इस Mac की TV लाइब्रेरी

TV ऐप की लाइब्रेरी में शो और एपिसोड की संख्या, और उसके डेटाबेस का आकार। वीडियो फ़ाइलें नहीं गिनी जातीं।

TV Library Viewer डेटाबेस

इस Mac पर TV Library Viewer का अपना डेटाबेस, जो लाइब्रेरी देखने वाले हर डिवाइस के साथ शेयर होता है।

हिस्साइसमें क्या है
शो की जानकारीAppleScript से दिए गए पूरे विवरण, और हर शो के कलाकार: अभिनेताओं के नाम और भूमिकाएँ।
अनुवादएपिसोड के शीर्षक और विवरण, उन भाषाओं में अनुवादित जिन पर ऐप सेट हैं।
कलाकार और टीमहर व्यक्ति की एक छोटी तस्वीर, और TVmaze और TMDb पर उनके पेजों के पते।
खाते और देखनाअकाउंट, मुख्य अकाउंट को छोड़कर हर अकाउंट का देखना, और अकाउंट के लॉग।
डेटाबेस संरचना और खाली जगहSQLite के अपने रिकॉर्ड, और वह जगह जिसे यह फिर से इस्तेमाल करता है।
हाल के बदलाववे बदलाव जो अभी डेटाबेस में शामिल नहीं हुए। यह काम समय-समय पर होता है।

किसी शो के कलाकार और टीम पहली बार उसका पेज खुलने पर, यहाँ या किसी भी डिवाइस पर, TVmaze और TMDb पर खोजे जाते हैं। लोगों का विवरण हर बार उन्हें खोलने पर लाया जाता है, इसलिए वह कभी पुराना नहीं होता, और सहेजा नहीं जाता। डेटाबेस फ़ाइल देखने के लिए Finder में दिखाएँ पर क्लिक करें।

कलाकार और टीम का विवरण: TMDb टोकन

TVmaze के लिए कुछ भी सेट अप नहीं करना पड़ता। TMDb (The Movie Database) निर्देशक और पटकथा लेखक, वे अभिनेता जो TVmaze में नहीं हैं, और जीवनी जोड़ता है, अक्सर आपकी भाषा में। इसके लिए आपका अपना टोकन चाहिए: TMDb अकाउंट वाले हर व्यक्ति को निजी, गैर-व्यावसायिक उपयोग के लिए मुफ़्त टोकन देता है। TV Library Viewer के साथ कोई टोकन नहीं आता।

  1. themoviedb.org पर एक मुफ़्त अकाउंट बनाएँ, और साइन इन करें।
  2. अपने अकाउंट आइकन पर क्लिक करें, Settings चुनें, फिर API पर क्लिक करें।
  3. API की का अनुरोध करें: Developer चुनें, शर्तें स्वीकार करें, और अपने उपयोग को निजी और गैर-व्यावसायिक बताएँ (उदाहरण के लिए, “Show cast and biographies in my own TV library app”)।
  4. जब की तैयार हो जाए, तो API Read Access Token कॉपी करें (लंबा वाला, छोटी API Key नहीं)।
  5. लाइब्रेरी वाले Mac पर, TV Library Viewer › सेटिंग्ज़ चुनें, स्टोरेज पर क्लिक करें, और उसे TMDb API Read Access Token में पेस्ट करें।
  6. जाँचें पर क्लिक करें। “TMDb यह टोकन स्वीकार करता है” का मतलब है कि यह काम करता है।

टोकन Mac के कीचेन में रखा जाता है। इसका उपयोग केवल लाइब्रेरी वाला Mac करता है; आपके दूसरे डिवाइस कलाकार और विवरण उसी Mac से पाते हैं। जिन शो को पहले खोजा जा चुका है उन्हें TMDb के कलाकार और टीम अगली बार उनका पेज खुलने पर मिलते हैं। अगर आप नया टोकन जाँचे बिना सेटिंग्ज़ बंद कर दें, तो उसकी जाँच तभी होती है, और अगर TMDb उसे अस्वीकार करे तो आपको बताया जाता है।

ध्यान दें: यह उत्पाद TMDB API का उपयोग करता है, लेकिन TMDB द्वारा इसका समर्थन या प्रमाणन नहीं किया गया है।

अनुवाद: एक Google कुंजी

एपिसोड के शीर्षक और विवरण इस Mac पर Apple के अनुवाद से, मुफ़्त में, हर डिवाइस की भाषा में अनुवादित होते हैं। यह ग्रीक, चेक, हंगेरियन, रोमानियाई, फ़ारसी, उर्दू या बांग्ला में अनुवाद नहीं कर सकता। इन भाषाओं के लिए अपनी Google Cloud Translation API कुंजी जोड़ें। इसकी ज़रूरत केवल लाइब्रेरी वाले Mac को है; उसे देखने वाले डिवाइस को नहीं। हर महीने पहले 5,00,000 अक्षर मुफ़्त हैं, और हर टेक्स्ट का अनुवाद केवल एक बार होता है।

  1. console.cloud.google.com पर जाएँ और अपने Google अकाउंट से साइन इन करें।
  2. एक प्रोजेक्ट बनाएँ: सबसे ऊपर प्रोजेक्ट मेनू पर क्लिक करें, फिर New Project पर, और उसे कोई नाम दें, जैसे “TV Library Viewer”।
  3. बिलिंग चालू करें: मेनू ☰ में Billing चुनें और एक बिलिंग अकाउंट जोड़ें। Google मुफ़्त उपयोग के लिए भी इसे माँगता है। सुरक्षित रहने के लिए, Budgets & alerts में एक बजट जोड़ें, जैसे $1।
  4. ☰ › APIs & Services › Library चुनें, Cloud Translation API खोजें, और Enable पर क्लिक करें।
  5. ☰ › APIs & Services › Credentials चुनें, फिर Create credentials › API key, और कुंजी कॉपी करें (यह “AIza” से शुरू होती है)।
  6. सुझाव: कुंजी के नाम पर क्लिक करें, API restrictions के नीचे Restrict key चुनें, Cloud Translation API पर टिक करें, और Save पर क्लिक करें, ताकि कुंजी केवल अनुवाद के लिए काम करे।
  7. लाइब्रेरी वाले Mac पर, TV Library Viewer › सेटिंग्ज़ चुनें, स्टोरेज पर क्लिक करें, कुंजी को Google Cloud Translation API कुंजी में पेस्ट करें, और जाँचें पर क्लिक करें।

कुंजी Mac के कीचेन में रखी जाती है और केवल इन सात भाषाओं के लिए उपयोग होती है। इसे किसी से साझा न करें: इससे अनुवादित हर चीज़ का बिल आपके Google अकाउंट में जाता है।

कैश

आर्टवर्क, और वे लाइब्रेरी जिन्हें इस Mac ने दूसरे Mac से देखा है। ज़रूरत पड़ने पर कैश फिर से बनाए जाते हैं, और जगह कम होने पर macOS उन्हें खाली कर देता है।
