AppleScript

TV Library Viewer can be scripted, for example from a script that imports episodes. Open its dictionary in Script Editor (File › Open Dictionary…) for the details.

CommandWhat it does
add episodeAdds a video file to the TV app's library (or finds it there) with its show, season, episode, title, genre and descriptions, and returns its persistent ID.
update episodeChanges an episode's details.
remove episodeRemoves an episode from the library. The file stays.
refresh libraryReads the library again.
create account, change account password, delete account, account names, account logManage accounts.

Long descriptions given this way are kept in TV Library Viewer's database, and put back when the TV app forgets them.
