En series medvirkende og stab slås op på TVmaze og TMDb, første gang dens side åbnes, her eller på en hvilken som helst enhed. Oplysninger om personer hentes, hver gang du åbner dem, så de aldrig er forældede, og de gemmes ikke. Klik på Vis i Finder for at se databasefilen.

Oplysninger om medvirkende og stab: et TMDb-token

TVmaze kræver ingen indstilling. TMDb (The Movie Database) tilføjer instruktører og manuskriptforfattere, skuespillere, som TVmaze ikke har, og biografier, ofte på dit sprog. Det kræver dit eget token: TMDb giver et gratis til alle med en konto til personlig, ikke-kommerciel brug. TV Library Viewer leveres ikke med et.

  1. Opret en gratis konto på themoviedb.org, og log ind.
  2. Klik på dit kontosymbol, vælg Settings, og klik derefter på API.
  3. Anmod om en API-nøgle: vælg Developer, accepter betingelserne, og beskriv din brug som personlig og ikke-kommerciel (f.eks. "Show cast and biographies in my own TV library app").
  4. Når nøglen er klar, skal du kopiere API Read Access Token (den lange, ikke den kortere API Key).
  5. Vælg TV Library Viewer › Indstillinger på den Mac, der har biblioteket, klik på Lagring, og indsæt det i TMDb API Read Access Token.
  6. Klik på Test. "TMDb godkender dette token." betyder, at det virker.

Tokenet gemmes i Mac'ens nøglering. Kun den Mac, der har biblioteket, bruger det; dine andre enheder får de medvirkende og detaljerne fra den Mac. Serier, der allerede er slået op, får TMDb's medvirkende og stab næste gang, deres side åbnes. Hvis du lukker Indstillinger uden at teste et nyt token, testes det da, og du får besked, hvis TMDb afviser det.

Bemærk: Dette produkt bruger TMDB API, men er ikke godkendt eller certificeret af TMDB.

Oversættelse: en Google-nøgle

Episodetitler og -beskrivelser oversættes til hver enheds sprog på denne Mac, gratis, med Apples oversættelse. Den kan ikke oversætte til græsk, tjekkisk, ungarsk, rumænsk, persisk, urdu eller bengali. Til de sprog skal du tilføje din egen Google Cloud Translation API key. Kun den Mac, der har biblioteket, skal bruge en; de enheder, der viser det, skal ikke. De første 500.000 tegn hver måned er gratis, og hver tekst oversættes kun én gang.

  1. Gå til console.cloud.google.com, og log ind med din Google-konto.
  2. Opret et projekt: klik på projektmenuen øverst, derefter på New Project, og giv det et navn som f.eks. "TV Library Viewer".
  3. Slå fakturering til: vælg Billing i menuen ☰, og tilknyt en faktureringskonto. Google kræver en, selv ved gratis brug. Tilføj for en sikkerheds skyld et budget, f.eks. 1 $, under Budgets & alerts.
  4. Vælg ☰ › APIs & Services › Library, søg efter Cloud Translation API, og klik på Enable.
  5. Vælg ☰ › APIs & Services › Credentials, derefter Create credentials › API key, og kopiér nøglen (den starter med "AIza").
  6. Anbefalet: klik på nøglens navn, vælg Restrict key under API restrictions, sæt flueben ved Cloud Translation API, og klik på Save, så nøglen kun virker til oversættelse.
  7. Vælg TV Library Viewer › Indstillinger på den Mac, der har biblioteket, klik på Lagring, indsæt nøglen i Google Cloud Translation API-nøgle, og klik på Test.

Nøglen opbevares i Macens nøglering og bruges kun til de syv sprog. Del den ikke med andre: alt, hvad der oversættes med den, faktureres til din Google-konto.

Cachelagre

Billeder og de biblioteker, som denne Mac har vist fra andre Mac-computere. Cachelagre oprettes igen efter behov, og macOS tømmer dem, når der er ved at være mangel på plads.
