Detail Pemeran dan Kru: token TMDb

TVmaze tidak memerlukan pengaturan apa pun. TMDb (The Movie Database) menambahkan sutradara dan penulis skenario, aktor yang tidak dimiliki TVmaze, serta biografi, sering kali dalam bahasa Anda. TMDb memerlukan token milik Anda sendiri: TMDb memberikannya gratis kepada siapa pun yang memiliki akun, untuk penggunaan pribadi dan nonkomersial. TV Library Viewer tidak menyertakan token.

  1. Buat akun gratis di themoviedb.org, lalu masuk.
  2. Klik ikon akun Anda, pilih Settings, lalu klik API.
  3. Minta kunci API: pilih Developer, terima persyaratannya, dan jelaskan penggunaan Anda sebagai pribadi dan nonkomersial (misalnya, "Show cast and biographies in my own TV library app").
  4. Setelah kunci siap, salin API Read Access Token (yang panjang, bukan API Key yang lebih pendek).
  5. Di Mac yang memiliki perpustakaan, pilih TV Library Viewer › Pengaturan, klik Penyimpanan, lalu tempelkan token ke API Read Access Token TMDb.
  6. Klik Uji. "TMDb menerima token ini" berarti token berfungsi.

Token disimpan di Rantai Kunci Mac. Hanya Mac yang memiliki perpustakaan yang menggunakannya; perangkat lain Anda mendapatkan pemeran dan detail dari Mac tersebut. Acara yang sudah dicari akan mendapatkan pemeran dan kru dari TMDb saat halamannya dibuka berikutnya. Jika Anda menutup Pengaturan tanpa menguji token baru, token akan diuji saat itu, dan Anda akan diberi tahu jika TMDb menolaknya.

Catatan: Produk ini menggunakan API TMDB tetapi tidak didukung atau disertifikasi oleh TMDB.

Terjemahan: kunci Google

Judul dan deskripsi episode diterjemahkan ke bahasa setiap perangkat di Mac ini, gratis, dengan Terjemahan dari Apple. Terjemahan tidak dapat menerjemahkan ke bahasa Yunani, Ceko, Hungaria, Rumania, Persia, Urdu, atau Bengali. Untuk bahasa tersebut, tambahkan kunci Google Cloud Translation API Anda sendiri. Hanya Mac yang memiliki perpustakaan yang memerlukannya; perangkat yang melihat perpustakaan tidak. 500.000 karakter pertama setiap bulan gratis, dan setiap teks hanya diterjemahkan sekali.

  1. Buka console.cloud.google.com dan masuk dengan akun Google Anda.
  2. Buat proyek: klik menu proyek di bagian atas, lalu New Project, dan beri nama seperti "TV Library Viewer".
  3. Aktifkan penagihan: di menu ☰, pilih Billing dan tautkan akun penagihan. Google memintanya bahkan untuk penggunaan gratis. Agar aman, tambahkan anggaran, misalnya US$1, di Budgets & alerts.
  4. Pilih ☰ › APIs & Services › Library, cari Cloud Translation API, lalu klik Enable.
  5. Pilih ☰ › APIs & Services › Credentials, lalu Create credentials › API key, dan salin kuncinya (diawali dengan "AIza").
  6. Disarankan: klik nama kunci, pilih Restrict key di bawah API restrictions, centang Cloud Translation API, lalu klik Save, sehingga kunci hanya berfungsi untuk terjemahan.
  7. Di Mac yang memiliki perpustakaan, pilih TV Library Viewer › Pengaturan, klik Penyimpanan, tempel kunci ke Kunci Google Cloud Translation API, lalu klik Uji.

Kunci disimpan di Rantai Kunci Mac dan hanya digunakan untuk ketujuh bahasa tersebut. Jangan bagikan kunci ini: apa pun yang diterjemahkan dengannya akan ditagihkan ke akun Google Anda.

Cache

Gambar, dan perpustakaan yang telah dilihat Mac ini dari Mac lain. Cache dibuat ulang saat diperlukan, dan macOS mengosongkannya saat ruang hampir habis.
