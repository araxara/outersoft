Bantuan TV Library Viewer › Referensi

AppleScript

TV Library Viewer dapat dikendalikan dengan skrip, misalnya dari skrip yang mengimpor episode. Buka kamusnya di Editor Skrip (File › Buka Kamus…) untuk detailnya.

PerintahFungsinya
add episodeMenambahkan file video ke perpustakaan app TV (atau menemukannya di sana) beserta acara, musim, episode, judul, genre, dan deskripsinya, lalu mengembalikan ID persistennya.
update episodeMengubah detail episode.
remove episodeMenghapus episode dari perpustakaan. Filenya tetap ada.
refresh libraryMembaca ulang perpustakaan.
create account, change account password, delete account, account names, account logMengelola akun.

Deskripsi panjang yang diberikan dengan cara ini disimpan di basis data TV Library Viewer, dan dikembalikan saat app TV melupakannya.
