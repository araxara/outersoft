La distribution et l’équipe d’une série sont recherchées sur TVmaze et TMDb la première fois que sa page est ouverte, ici ou sur n’importe quel appareil. Les informations sur les personnes sont récupérées à chaque ouverture : elles ne sont donc jamais dépassées, et ne sont pas stockées. Cliquez sur Afficher dans le Finder pour voir le fichier de la base de données.

Détails sur la distribution et l’équipe : un jeton TMDb

TVmaze ne demande aucune configuration. TMDb (The Movie Database) ajoute les réalisateurs et les scénaristes, les acteurs que TVmaze n’a pas, et des biographies, souvent dans votre langue. Il faut pour cela votre propre jeton : TMDb en fournit un gratuitement à toute personne disposant d’un compte, pour un usage personnel et non commercial. TV Library Viewer n’en fournit pas.

  1. Créez un compte gratuit sur themoviedb.org, puis connectez-vous.
  2. Cliquez sur l’icône de votre compte, choisissez Settings, puis cliquez sur API.
  3. Demandez une clé API : choisissez Developer, acceptez les conditions et décrivez votre usage comme personnel et non commercial (par exemple « Afficher la distribution et les biographies dans ma propre app de bibliothèque TV »).
  4. Lorsque la clé est prête, copiez l’API Read Access Token (le long, pas l’API Key plus courte).
  5. Sur le Mac qui contient la bibliothèque, choisissez TV Library Viewer › Réglages, cliquez sur Stockage, puis collez-le dans API Read Access Token de TMDb.
  6. Cliquez sur Tester. « TMDb accepte ce jeton. » signifie qu’il fonctionne.

Le jeton est conservé dans le trousseau du Mac. Seul le Mac qui contient la bibliothèque l’utilise ; vos autres appareils obtiennent la distribution et les détails de ce Mac. Les séries déjà recherchées reçoivent la distribution et l’équipe de TMDb à la prochaine ouverture de leur page. Si vous fermez les réglages sans tester un nouveau jeton, il est testé à ce moment-là, et vous êtes prévenu si TMDb le refuse.

Remarque : Ce produit utilise l’API TMDB, mais n’est ni approuvé ni certifié par TMDB.

Traduction : une clé Google

Les titres et les descriptions des épisodes sont traduits dans la langue de chaque appareil sur ce Mac, gratuitement, avec la traduction d’Apple. Celle-ci ne peut pas traduire en grec, tchèque, hongrois, roumain, persan, ourdou ni bengali. Pour ces langues, ajoutez votre propre clé Google Cloud Translation API. Seul le Mac qui contient la bibliothèque en a besoin, pas les appareils qui la consultent. Les 500 000 premiers caractères de chaque mois sont gratuits, et chaque texte n’est traduit qu’une seule fois.

  1. Rendez-vous sur console.cloud.google.com et connectez-vous avec votre compte Google.
  2. Créez un projet : cliquez sur le menu des projets en haut, puis sur New Project, et donnez-lui un nom, par exemple « TV Library Viewer ».
  3. Activez la facturation : dans le menu ☰, choisissez Billing et associez un compte de facturation. Google en demande un même pour un usage gratuit. Par précaution, ajoutez un budget, par exemple 1 $, sous Budgets & alerts.
  4. Choisissez ☰ › APIs & Services › Library, recherchez Cloud Translation API, puis cliquez sur Enable.
  5. Choisissez ☰ › APIs & Services › Credentials, puis Create credentials › API key, et copiez la clé (elle commence par « AIza »).
  6. Recommandé : cliquez sur le nom de la clé, choisissez Restrict key sous API restrictions, cochez Cloud Translation API, puis cliquez sur Save, afin que la clé ne serve qu’à la traduction.
  7. Sur le Mac qui contient la bibliothèque, choisissez TV Library Viewer › Réglages, cliquez sur Stockage, collez la clé dans Clé Google Cloud Translation API, puis cliquez sur Tester.

La clé est conservée dans le trousseau du Mac et n’est utilisée que pour ces sept langues. Ne la partagez pas : tout ce qui est traduit avec elle est facturé sur votre compte Google.

Caches

Les illustrations, et les bibliothèques que ce Mac a affichées depuis d’autres Mac. Les caches sont recréés au besoin, et macOS les vide lorsque l’espace vient à manquer.
