CommandeEffet
Ouvrir une bibliothèque… ⌘OOuvre une autre bibliothèque de l’app TV sur ce Mac : un paquet .tvlibrary, ou le fichier Library.tvdb qu’il contient.
Se connecter à une bibliothèque partagée… ⌘KOuvre une bibliothèque partagée par un autre Mac : sur ce réseau, par SSH ou à une adresse. Consultez Se connecter à une bibliothèque partagée.
Compte…Votre compte sur la bibliothèque partagée que vous consultez : ses statistiques, les appareils depuis lesquels il est utilisé, et la modification de son mot de passe.
Se connecter avec un compte…
Se connecter avec un autre compte…		Vous connecte à la bibliothèque partagée avec un compte, pour que vos visionnages vous appartiennent.
Changer de bibliothèqueRevient à la Bibliothèque de ce Mac, ou à une bibliothèque partagée que vous avez déjà utilisée.
Actualiser la bibliothèque ⌘RRelit la bibliothèque. Elle se met normalement à jour toute seule, peu après que l’app TV a enregistré une modification.
