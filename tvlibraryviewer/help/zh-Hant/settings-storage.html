TV Library Viewer 資料庫

TV Library Viewer 在這台 Mac 上的自有資料庫，與每部觀看該資料庫的裝置共享。

部分包含的內容
劇集資訊透過 AppleScript 提供的完整描述，以及每個節目的演員：演員的姓名和角色。
翻譯已翻譯成各 App 所設語言的劇集標題和簡介。
演職員每個人的一張小照片，以及其在 TVmaze 和 TMDb 上的頁面位址。
帳號與觀看帳號、主要帳號以外所有帳號的觀看紀錄，以及帳號的記錄。
資料庫結構與可用空間SQLite 本身的紀錄，以及它會重複使用的空間。
最近的變更尚未併入資料庫的變更。它會不時進行合併。

節目的演職員會在其頁面第一次打開時（無論是在這裡或在任何裝置上）從 TVmaze 和 TMDb 查詢。人物詳情會在每次打開時取得，因此絕不會過時，也不會被儲存。按一下在 Finder 中顯示即可查看資料庫檔案。

演職員詳情：TMDb 權杖

TVmaze 不需要任何設定。TMDb（The Movie Database）會加入導演和編劇、TVmaze 沒有的演員以及人物簡介，而且通常有你的語言版本。它需要你自己的權杖：TMDb 會免費提供權杖給任何擁有帳號的人，供個人非商業用途使用。TV Library Viewer 並未附帶權杖。

  1. 在 themoviedb.org 建立免費帳號並登入。
  2. 按一下你的帳號圖像，選擇Settings，然後按一下API。
  3. 申請 API 金鑰：選擇Developer，接受條款，並將用途描述為個人和非商業用途（例如「在我自己的電視資料庫 App 中顯示演員和人物簡介」）。
  4. 金鑰準備好後，拷貝API Read Access Token（較長的那個，而不是較短的 API Key）。
  5. 在存有資料庫的 Mac 上，選擇TV Library Viewer › 設定，按一下儲存空間，然後將其貼到TMDb API Read Access Token中。
  6. 按一下測試。顯示「TMDb 接受此權杖。」即表示可以使用。

權杖會保存在 Mac 的鑰匙圈中。只有存有資料庫的 Mac 會使用它；你的其他裝置會從那台 Mac 取得演員和詳細資訊。已經查詢過的節目會在下次打開其頁面時取得 TMDb 的演職員。如果你在未測試新權杖的情況下關閉設定，屆時會對其進行測試，若 TMDb 拒絕，你會收到通知。

注意：本產品使用 TMDB API，但未經 TMDB 認可或認證。

翻譯：Google 密鑰

劇集標題和描述會在這台 Mac 上使用 Apple 的翻譯功能免費翻譯成每部裝置的語言。但它無法翻譯成希臘文、捷克文、匈牙利文、羅馬尼亞文、波斯文、烏爾都文或孟加拉文。如需這些語言，請加入你自己的 Google Cloud Translation API 密鑰。只有存有資料庫的 Mac 需要密鑰；觀看資料庫的裝置不需要。每月前 50 萬個字元免費，而且每段文字只會翻譯一次。

  1. 前往 console.cloud.google.com，並使用你的 Google 帳號登入。
  2. 建立專案：按一下頂部的專案選單，然後按一下New Project，並為其命名，例如「TV Library Viewer」。
  3. 開啟帳單：在選單 ☰ 中選擇Billing，然後連結一個帳單帳戶。即使免費使用，Google 也會要求提供帳單帳戶。為了安全起見，請在Budgets & alerts下加入預算，例如 1 美元。
  4. 選擇 ☰ › APIs & Services › Library，搜尋Cloud Translation API，然後按一下Enable。
  5. 選擇 ☰ › APIs & Services › Credentials，然後選擇Create credentials › API key，並拷貝密鑰（以「AIza」開頭）。
  6. 建議：按一下密鑰的名稱，在 API restrictions 下選擇Restrict key，勾選Cloud Translation API，然後按一下Save，這樣密鑰就只能用於翻譯。
  7. 在存有資料庫的 Mac 上，選擇TV Library Viewer › 設定，按一下儲存空間，將密鑰貼到Google Cloud Translation API 密鑰中，然後按一下測試。

密鑰會保存在 Mac 的鑰匙圈中，而且只用於這七種語言。請勿與他人分享密鑰：使用它翻譯的任何內容都會向你的 Google 帳號收費。
