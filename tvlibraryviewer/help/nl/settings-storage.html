De cast en crew van een serie worden op TVmaze en TMDb opgezocht de eerste keer dat de pagina wordt geopend, hier of op een ander apparaat. Gegevens over personen worden elke keer opgehaald als je ze opent, zodat ze nooit verouderd zijn, en worden niet bewaard. Klik op Toon in Finder om het databasebestand te zien.

Gegevens over cast en crew: een TMDb-token

TVmaze hoef je niet in te stellen. TMDb (The Movie Database) voegt regisseurs en scenarioschrijvers toe, acteurs die TVmaze niet heeft, en biografieën, vaak in jouw taal. Daarvoor is een eigen token nodig: TMDb geeft er gratis een aan iedereen met een account, voor persoonlijk, niet-commercieel gebruik. TV Library Viewer wordt niet met een token geleverd.

  1. Maak een gratis account aan op themoviedb.org en log in.
  2. Klik op je accountsymbool, kies Settings en klik op API.
  3. Vraag een API-sleutel aan: kies Developer, accepteer de voorwaarden en omschrijf je gebruik als persoonlijk en niet-commercieel (bijvoorbeeld 'Show cast and biographies in my own TV library app').
  4. Als de sleutel klaar is, kopieer je het API Read Access Token (het lange, niet de kortere API Key).
  5. Kies op de Mac met de bibliotheek TV Library Viewer › Instellingen, klik op Opslag en plak het in TMDb API Read Access Token.
  6. Klik op Test. 'TMDb accepteert dit token.' betekent dat het werkt.

Het token wordt bewaard in de sleutelhanger van de Mac. Alleen de Mac met de bibliotheek gebruikt het; je andere apparaten krijgen de cast en details van die Mac. Series die al zijn opgezocht, krijgen de cast en crew van TMDb de volgende keer dat hun pagina wordt geopend. Als je Instellingen sluit zonder een nieuw token te testen, wordt het op dat moment getest, en krijg je een melding als TMDb het weigert.

Opmerking: Dit product gebruikt de TMDB API, maar wordt niet onderschreven of gecertificeerd door TMDB.

Vertaling: een Google-sleutel

Afleveringstitels en -beschrijvingen worden op deze Mac gratis in de taal van elk apparaat vertaald, met de vertaalfunctie van Apple. Die kan niet vertalen naar het Grieks, Tsjechisch, Hongaars, Roemeens, Perzisch, Urdu of Bengaals. Voeg daarvoor je eigen Google Cloud Translation API key toe. Alleen de Mac met de bibliotheek heeft er een nodig; de apparaten die ernaar kijken niet. De eerste 500.000 tekens per maand zijn gratis, en elke tekst wordt maar één keer vertaald.

  1. Ga naar console.cloud.google.com en log in met je Google-account.
  2. Maak een project: klik bovenaan op het projectmenu, dan op New Project, en geef het een naam zoals 'TV Library Viewer'.
  3. Zet facturering aan: kies in het menu ☰ Billing en koppel een factureringsaccount. Google vraagt er ook een voor gratis gebruik. Voeg voor de zekerheid een budget toe, bijvoorbeeld $ 1, onder Budgets & alerts.
  4. Kies ☰ › APIs & Services › Library, zoek naar Cloud Translation API en klik op Enable.
  5. Kies ☰ › APIs & Services › Credentials, dan Create credentials › API key, en kopieer de sleutel (die begint met 'AIza').
  6. Aanbevolen: klik op de naam van de sleutel, kies Restrict key onder API restrictions, vink Cloud Translation API aan en klik op Save, zodat de sleutel alleen voor vertalen werkt.
  7. Kies op de Mac met de bibliotheek TV Library Viewer › Instellingen, klik op Opslag, plak de sleutel in Google Cloud Translation API-sleutel en klik op Test.

De sleutel wordt bewaard in de sleutelhanger van de Mac en alleen voor die zeven talen gebruikt. Deel hem niet: alles wat ermee wordt vertaald, wordt aan je Google-account gefactureerd.
