Distribuția și echipa unui serial sunt căutate pe TVmaze și TMDb prima dată când i se deschide pagina, aici sau pe orice dispozitiv. Detaliile persoanelor sunt preluate de fiecare dată când le deschizi, așa că nu sunt niciodată învechite, și nu sunt stocate. Fă clic pe Afișează în Finder pentru a vedea fișierul bazei de date.

Detalii despre distribuție și echipă: un token TMDb

TVmaze nu necesită nicio configurare. TMDb (The Movie Database) adaugă regizori și scenariști, actori pe care TVmaze nu îi are și biografii, adesea în limba ta. Are nevoie de un token propriu: TMDb oferă unul gratuit oricui are un cont, pentru uz personal, necomercial. TV Library Viewer nu vine cu unul.

  1. Creează un cont gratuit pe themoviedb.org și autentifică-te.
  2. Fă clic pe pictograma contului, alege Settings, apoi fă clic pe API.
  3. Solicită o cheie API: alege Developer, acceptă termenii și descrie utilizarea ca personală și necomercială (de exemplu, „Afișarea distribuției și a biografiilor în propria mea aplicație de bibliotecă TV”).
  4. Când cheia este gata, copiază API Read Access Token (cel lung, nu API Key, cel mai scurt).
  5. Pe Mac-ul cu biblioteca, alege TV Library Viewer › Configurări, fă clic pe Stocare și lipește-l în API Read Access Token TMDb.
  6. Fă clic pe Testează. „TMDb acceptă acest token” înseamnă că funcționează.

Tokenul este păstrat în Portchei pe Mac. Doar Mac-ul cu biblioteca îl folosește; celelalte dispozitive primesc distribuția și detaliile de la acel Mac. Serialele deja căutate primesc distribuția și echipa de la TMDb data următoare când li se deschide pagina. Dacă închizi Configurări fără să testezi un token nou, acesta este testat atunci și ești anunțat dacă TMDb îl refuză.

Notă: Acest produs folosește API-ul TMDB, dar nu este aprobat sau certificat de TMDB.

Traducere: o cheie Google

Titlurile și descrierile episoadelor sunt traduse în limba fiecărui dispozitiv pe acest Mac, gratuit, cu funcția de traducere Apple. Aceasta nu poate traduce în greacă, cehă, maghiară, română, persană, urdu sau bengaleză. Pentru acestea, adaugă propria cheie Google Cloud Translation API. Doar Macul cu biblioteca are nevoie de una, nu și dispozitivele care o vizionează. Primele 500.000 de caractere în fiecare lună sunt gratuite, iar fiecare text este tradus o singură dată.

  1. Accesează console.cloud.google.com și autentifică-te cu contul tău Google.
  2. Creează un proiect: fă clic pe meniul de proiecte din partea de sus, apoi pe New Project, și dă-i un nume, de exemplu „TV Library Viewer”.
  3. Activează facturarea: în meniul ☰, alege Billing și asociază un cont de facturare. Google cere unul chiar și pentru utilizarea gratuită. Pentru siguranță, adaugă un buget, de exemplu 1 USD, în Budgets & alerts.
  4. Alege ☰ › APIs & Services › Library, caută Cloud Translation API și fă clic pe Enable.
  5. Alege ☰ › APIs & Services › Credentials, apoi Create credentials › API key, și copiază cheia (începe cu „AIza”).
  6. Recomandat: fă clic pe numele cheii, alege Restrict key sub API restrictions, bifează Cloud Translation API și fă clic pe Save, ca cheia să funcționeze doar pentru traducere.
  7. Pe Macul cu biblioteca, alege TV Library Viewer › Configurări, fă clic pe Stocare, lipește cheia în Cheie Google Cloud Translation API și fă clic pe Testează.

Cheia este păstrată în Brelocul Macului și este folosită doar pentru aceste șapte limbi. Nu o partaja: tot ce se traduce cu ea este facturat în contul tău Google.

Memorii cache

Imaginile și bibliotecile pe care acest Mac le-a afișat de pe alte Mac-uri. Memoriile cache sunt refăcute când este nevoie, iar macOS le golește când rămâne fără spațiu.
