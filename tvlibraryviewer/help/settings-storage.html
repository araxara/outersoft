A show's cast and crew are looked up on TVmaze and TMDb the first time its page is opened, here or on any device. People's details are fetched each time you open them, so they're never out of date, and aren't stored. Click Show in Finder to see the database file.

Cast and Crew Details: a TMDb token

TVmaze needs nothing set up. TMDb (The Movie Database) adds directors and screenwriters, actors TVmaze doesn't have, and biographies, often in your language. It needs a token of your own: TMDb gives one free to anyone with an account, for personal, non-commercial use. TV Library Viewer doesn't come with one.

  1. Create a free account at themoviedb.org, and sign in.
  2. Click your account icon, choose Settings, then click API.
  3. Request an API key: choose Developer, accept the terms, and describe your use as personal and non-commercial (for example, "Show cast and biographies in my own TV library app").
  4. When the key is ready, copy the API Read Access Token (the long one, not the shorter API Key).
  5. On the Mac with the library, choose TV Library Viewer › Settings, click Storage, and paste it into TMDb API Read Access Token.
  6. Click Test. "TMDb accepts this token" means it works.

The token is kept in the Mac's Keychain. Only the Mac with the library uses it; your other devices get the cast and details from that Mac. Shows already looked up get TMDb's cast and crew the next time their page is opened. If you close Settings without testing a new token, it's tested then, and you're told if TMDb refuses it.

Note: This product uses the TMDB API but is not endorsed or certified by TMDB.

Translation: a Google key

Episode titles and descriptions are translated into each device's language on this Mac, free, with Apple's Translation. It can't translate into Greek, Czech, Hungarian, Romanian, Persian, Urdu or Bengali. For those, add your own Google Cloud Translation API key. Only the Mac with the library needs one; the devices viewing it don't. The first 500,000 characters each month are free, and each text is translated only once.

  1. Go to console.cloud.google.com and sign in with your Google account.
  2. Create a project: click the project menu at the top, then New Project, and give it a name such as "TV Library Viewer".
  3. Turn on billing: in the menu ☰, choose Billing and link a billing account. Google asks for one even for free use. To be safe, add a budget, such as $1, under Budgets & alerts.
  4. Choose ☰ › APIs & Services › Library, search for Cloud Translation API, and click Enable.
  5. Choose ☰ › APIs & Services › Credentials, then Create credentials › API key, and copy the key (it starts with "AIza").
  6. Recommended: click the key's name, choose Restrict key under API restrictions, tick Cloud Translation API, and click Save, so the key works only for translation.
  7. On the Mac with the library, choose TV Library Viewer › Settings, click Storage, paste the key into Google Cloud Translation API Key, and click Test.

The key is kept in the Mac's Keychain and is used only for those seven languages. Don't share it: anything translated with it is billed to your Google account.
