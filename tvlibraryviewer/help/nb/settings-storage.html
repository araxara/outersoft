Rollelisten og staben til en serie slås opp på TVmaze og TMDb første gang siden åpnes, her eller på en annen enhet. Personopplysninger hentes hver gang du åpner dem, så de aldri er utdaterte, og lagres ikke. Klikk på Vis i Finder for å se databasefilen.

Detaljer om rolleliste og stab: et TMDb-token

TVmaze trenger ikke noe oppsett. TMDb (The Movie Database) legger til regissører og manusforfattere, skuespillere TVmaze ikke har, og biografier, ofte på ditt språk. Det krever et eget token: TMDb gir et gratis til alle med en konto, til personlig, ikke-kommersiell bruk. TV Library Viewer følger ikke med et.

  1. Opprett en gratis konto på themoviedb.org, og logg inn.
  2. Klikk på kontosymbolet, velg Settings, og klikk deretter på API.
  3. Be om en API-nøkkel: Velg Developer, godta vilkårene, og beskriv bruken som personlig og ikke-kommersiell (for eksempel «Show cast and biographies in my own TV library app»).
  4. Når nøkkelen er klar, kopierer du API Read Access Token (den lange, ikke den kortere API Key).
  5. På Macen med biblioteket velger du TV Library Viewer › Innstillinger, klikker på Lagring og limer det inn i TMDb API Read Access Token.
  6. Klikk på Test. «TMDb godtar dette tokenet» betyr at det fungerer.

Tokenet lagres i nøkkelringen på Macen. Bare Macen med biblioteket bruker det; de andre enhetene dine får rollelisten og detaljene fra den Macen. Serier som allerede er slått opp, får rollelisten og staben fra TMDb neste gang siden deres åpnes. Hvis du lukker Innstillinger uten å teste et nytt token, testes det da, og du får beskjed hvis TMDb avviser det.

Merk: Dette produktet bruker TMDB API, men er ikke godkjent eller sertifisert av TMDB.

Oversettelse: en Google-nøkkel

Episodetitler og -beskrivelser oversettes til språket på hver enhet her på Macen, gratis, med Apples oversettelsesfunksjon. Den kan ikke oversette til gresk, tsjekkisk, ungarsk, rumensk, persisk, urdu eller bengali. For disse kan du legge til din egen Google Cloud Translation API-nøkkel. Bare Macen med biblioteket trenger en, ikke enhetene som viser det. De første 500 000 tegnene hver måned er gratis, og hver tekst oversettes bare én gang.

  1. Gå til console.cloud.google.com, og logg på med Google-kontoen din.
  2. Opprett et prosjekt: Klikk på prosjektmenyen øverst, deretter på New Project, og gi det et navn, for eksempel «TV Library Viewer».
  3. Slå på fakturering: Velg Billing i menyen ☰, og koble til en faktureringskonto. Google krever en selv for gratis bruk. For sikkerhets skyld kan du legge til et budsjett, for eksempel 1 dollar, under Budgets & alerts.
  4. Velg ☰ › APIs & Services › Library, søk etter Cloud Translation API, og klikk på Enable.
  5. Velg ☰ › APIs & Services › Credentials, deretter Create credentials › API key, og kopier nøkkelen (den begynner med «AIza»).
  6. Anbefalt: Klikk på navnet til nøkkelen, velg Restrict key under API restrictions, kryss av for Cloud Translation API, og klikk på Save, slik at nøkkelen bare fungerer for oversettelse.
  7. På Macen med biblioteket velger du TV Library Viewer › Innstillinger, klikker på Lagring, limer inn nøkkelen i Google Cloud Translation API-nøkkel og klikker på Test.

Nøkkelen oppbevares i nøkkelringen på Macen og brukes bare for disse sju språkene. Ikke del den: Alt som oversettes med den, faktureres Google-kontoen din.
