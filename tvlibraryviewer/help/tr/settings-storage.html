Oyuncu ve ekip ayrıntıları: TMDb belirteci

TVmaze herhangi bir ayar gerektirmez. TMDb (The Movie Database) yönetmenleri ve senaristleri, TVmaze’de bulunmayan oyuncuları ve çoğu zaman sizin dilinizde biyografileri ekler. Bunun için size ait bir belirteç gerekir: TMDb, hesabı olan herkese kişisel ve ticari olmayan kullanım için ücretsiz bir belirteç verir. TV Library Viewer bir belirteçle birlikte gelmez.

  1. themoviedb.org’da ücretsiz bir hesap oluşturun ve giriş yapın.
  2. Hesap simgenizi tıklayın, Settings seçeneğini seçin, sonra API seçeneğini tıklayın.
  3. Bir API anahtarı isteyin: Developer seçeneğini seçin, koşulları kabul edin ve kullanımınızı kişisel ve ticari olmayan olarak tanımlayın (örneğin, “Show cast and biographies in my own TV library app”).
  4. Anahtar hazır olduğunda API Read Access Token değerini kopyalayın (daha kısa olan API Key’i değil, uzun olanı).
  5. Arşivin bulunduğu Mac’te TV Library Viewer › Ayarlar komutunu seçin, Depolama seçeneğini tıklayın ve belirteci TMDb API Read Access Token alanına yapıştırın.
  6. Sına düğmesini tıklayın. “TMDb bu belirteci kabul ediyor.” iletisi çalıştığı anlamına gelir.

Belirteç Mac’in Anahtar Zinciri’nde saklanır. Onu yalnızca arşivin bulunduğu Mac kullanır; diğer aygıtlarınız oyuncuları ve ayrıntıları o Mac’ten alır. Daha önce aranmış diziler, sayfaları bir sonraki açılışta TMDb’nin oyuncu ve ekip bilgilerini alır. Ayarlar’ı yeni bir belirteci sınamadan kapatırsanız belirteç o anda sınanır ve TMDb onu reddederse size bildirilir.

Not: Bu ürün TMDB API’sini kullanır ancak TMDB tarafından onaylanmamış veya sertifikalandırılmamıştır.

Çeviri: Google anahtarı

Bölüm adları ve açıklamaları, bu Mac’te Apple’ın Çeviri özelliğiyle ücretsiz olarak her aygıtın diline çevrilir. Ancak bu özellik Yunanca, Çekçe, Macarca, Romence, Farsça, Urduca veya Bengalceye çeviri yapamaz. Bu diller için kendi Google Cloud Translation API anahtarınızı ekleyin. Anahtar yalnızca arşivin bulunduğu Mac’te gerekir; arşivi görüntüleyen aygıtlarda gerekmez. Her ay ilk 500.000 karakter ücretsizdir ve her metin yalnızca bir kez çevrilir.

  1. console.cloud.google.com adresine gidin ve Google hesabınızla giriş yapın.
  2. Bir proje oluşturun: üstteki proje menüsünü tıklayın, sonra New Project seçeneğini tıklayın ve projeye “TV Library Viewer” gibi bir ad verin.
  3. Faturalandırmayı açın: ☰ menüsünde Billing seçeneğini seçin ve bir faturalandırma hesabı bağlayın. Google, ücretsiz kullanım için bile bir hesap ister. Güvende olmak için Budgets & alerts bölümünde 1 $ gibi bir bütçe ekleyin.
  4. ☰ › APIs & Services › Library seçeneğini seçin, Cloud Translation API araması yapın ve Enable düğmesini tıklayın.
  5. ☰ › APIs & Services › Credentials seçeneğini, sonra Create credentials › API key seçeneğini seçin ve anahtarı kopyalayın (“AIza” ile başlar).
  6. Önerilir: anahtarın adını tıklayın, API restrictions altında Restrict key seçeneğini seçin, Cloud Translation API kutusunu işaretleyin ve Save düğmesini tıklayın; böylece anahtar yalnızca çeviri için çalışır.
  7. Arşivin bulunduğu Mac’te TV Library Viewer › Ayarlar komutunu seçin, Depolama seçeneğini tıklayın, anahtarı Google Cloud Translation API anahtarı alanına yapıştırın ve Sına düğmesini tıklayın.

Anahtar Mac’in Anahtar Zinciri’nde saklanır ve yalnızca bu yedi dil için kullanılır. Anahtarı kimseyle paylaşmayın: onunla çevrilen her şey Google hesabınıza faturalandırılır.
