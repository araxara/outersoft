База даних TV Library Viewer

Власна база даних TV Library Viewer на цьому Mac, спільна для всіх пристроїв, що переглядають медіатеку.

Відомості про людей завантажуються щоразу, коли ви їх відкриваєте, тому вони завжди актуальні й не зберігаються. Клацніть Показати у Finder, щоб побачити файл бази даних.

Відомості про акторів і знімальну групу: токен TMDb

TVmaze не потребує налаштування. TMDb (The Movie Database) додає режисерів і сценаристів, акторів, яких немає на TVmaze, і біографії, часто вашою мовою. Для цього потрібен власний токен: TMDb безкоштовно дає його кожному, хто має обліковий запис, для особистого некомерційного використання. TV Library Viewer не постачається з токеном.

  1. Створіть безкоштовний обліковий запис на themoviedb.org і ввійдіть.
  2. Клацніть значок облікового запису, виберіть Settings і клацніть API.
  3. Надішліть запит на ключ API: виберіть Developer, прийміть умови й опишіть використання як особисте й некомерційне (наприклад, «Show cast and biographies in my own TV library app»).
  4. Коли ключ буде готовий, скопіюйте API Read Access Token (довгий, а не коротший API Key).
  5. На Mac із медіатекою виберіть TV Library Viewer › Параметри, клацніть Сховище і вставте його в поле API Read Access Token TMDb.
  6. Клацніть Перевірити. Повідомлення «TMDb приймає цей токен» означає, що все працює.

Токен зберігається у в’язці ключів Mac. Використовує його лише Mac із медіатекою; інші ваші пристрої отримують акторів і подробиці з цього Mac. Серіали, які вже шукали, отримають акторів і знімальну групу з TMDb наступного разу, коли відкриють їхню сторінку. Якщо закрити параметри, не перевіривши новий токен, його буде перевірено тоді, і вам повідомлять, якщо TMDb його відхилить.

Примітка. Цей продукт використовує API TMDB, але не схвалений і не сертифікований TMDB.

Переклад: ключ Google

Назви й описи епізодів перекладаються мовою кожного пристрою на цьому Mac, безкоштовно, за допомогою Перекладу від Apple. Він не перекладає грецькою, чеською, угорською, румунською, перською, урду та бенгальською. Для цих мов додайте власний ключ Google Cloud Translation API. Він потрібен лише Mac із медіатекою; пристроям, які її переглядають, — ні. Перші 500 000 символів щомісяця безкоштовні, і кожен текст перекладається лише один раз.

  1. Перейдіть на console.cloud.google.com і ввійдіть зі своїм обліковим записом Google.
  2. Створіть проєкт: клацніть меню проєктів угорі, потім New Project, і дайте йому назву, наприклад «TV Library Viewer».
  3. Увімкніть оплату: у меню ☰ виберіть Billing і під’єднайте платіжний обліковий запис. Google вимагає його навіть для безкоштовного використання. Для певності додайте бюджет, наприклад 1 $, у розділі Budgets & alerts.
  4. Виберіть ☰ › APIs & Services › Library, знайдіть Cloud Translation API і клацніть Enable.
  5. Виберіть ☰ › APIs & Services › Credentials, потім Create credentials › API key, і скопіюйте ключ (він починається з «AIza»).
  6. Рекомендовано: клацніть назву ключа, виберіть Restrict key у розділі API restrictions, позначте Cloud Translation API і клацніть Save, щоб ключ працював лише для перекладу.
  7. На Mac із медіатекою виберіть TV Library Viewer › Параметри, клацніть Сховище, вставте ключ у поле Ключ Google Cloud Translation API і клацніть Перевірити.

Ключ зберігається у в’язці ключів Mac і використовується лише для цих семи мов. Нікому його не давайте: усе, що перекладено з ним, оплачується з вашого облікового запису Google.

Кеші

Обкладинки й медіатеки, які цей Mac переглядав з інших Mac. Кеші створюються знову, коли потрібно, а macOS очищує їх, коли бракує місця.
