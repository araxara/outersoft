Βιβλιοθήκη TV αυτού του Mac

Ο αριθμός σειρών και επεισοδίων στη βιβλιοθήκη της εφαρμογής TV και το μέγεθος της βάσης δεδομένων της. Τα αρχεία βίντεο δεν υπολογίζονται.

Βάση δεδομένων TV Library Viewer

Η βάση δεδομένων του ίδιου του TV Library Viewer σε αυτό το Mac, κοινόχρηστη με κάθε συσκευή που προβάλλει τη βιβλιοθήκη.

ΤμήμαΤι περιέχει
Πληροφορίες σειρώνΠλήρεις περιγραφές που δόθηκαν μέσω AppleScript και τους ηθοποιούς κάθε σειράς: τα ονόματα και τους ρόλους τους.
ΜεταφράσειςΤίτλοι και περιγραφές επεισοδίων μεταφρασμένοι στις γλώσσες των εφαρμογών.
Ηθοποιοί και συντελεστέςΜια μικρή φωτογραφία για κάθε πρόσωπο και τις διευθύνσεις των σελίδων του στο TVmaze και στο TMDb.
Λογαριασμοί και παρακολούθησηΤους λογαριασμούς, τις προβολές κάθε λογαριασμού εκτός από τον κύριο και τα αρχεία καταγραφής των λογαριασμών.
Δομή βάσης δεδομένων και ελεύθερος χώροςΤις εσωτερικές εγγραφές του SQLite και χώρο που επαναχρησιμοποιεί.
Πρόσφατες αλλαγέςΑλλαγές που δεν έχουν ενσωματωθεί ακόμα στη βάση δεδομένων. Αυτό γίνεται κατά διαστήματα.

Οι ηθοποιοί και οι συντελεστές μιας σειράς αναζητούνται στο TVmaze και στο TMDb την πρώτη φορά που ανοίγει η σελίδα της, εδώ ή σε οποιαδήποτε συσκευή. Τα στοιχεία των προσώπων ανακτώνται κάθε φορά που τα ανοίγετε, ώστε να μην είναι ποτέ παρωχημένα, και δεν αποθηκεύονται. Κάντε κλικ στην Εμφάνιση στο Finder για να δείτε το αρχείο της βάσης δεδομένων.

Στοιχεία ηθοποιών και συντελεστών: ένα διακριτικό TMDb

Το TVmaze δεν χρειάζεται καμία ρύθμιση. Το TMDb (The Movie Database) προσθέτει σκηνοθέτες και σεναριογράφους, ηθοποιούς που δεν έχει το TVmaze και βιογραφικά, συχνά στη γλώσσα σας. Χρειάζεται ένα δικό σας διακριτικό: το TMDb δίνει ένα δωρεάν σε οποιονδήποτε έχει λογαριασμό, για προσωπική, μη εμπορική χρήση. Το TV Library Viewer δεν περιλαμβάνει κάποιο.

  1. Δημιουργήστε έναν δωρεάν λογαριασμό στο themoviedb.org και συνδεθείτε.
  2. Κάντε κλικ στο εικονίδιο του λογαριασμού σας, επιλέξτε Settings και μετά κάντε κλικ στο API.
  3. Ζητήστε ένα κλειδί API: επιλέξτε Developer, αποδεχτείτε τους όρους και περιγράψτε τη χρήση σας ως προσωπική και μη εμπορική (για παράδειγμα, «Εμφάνιση ηθοποιών και βιογραφικών στη δική μου εφαρμογή βιβλιοθήκης TV»).
  4. Όταν το κλειδί είναι έτοιμο, αντιγράψτε το API Read Access Token (το μεγάλο, όχι το συντομότερο API Key).
  5. Στο Mac με τη βιβλιοθήκη, επιλέξτε TV Library Viewer › Ρυθμίσεις, κάντε κλικ στην Αποθήκευση και επικολλήστε το στο TMDb API Read Access Token.
  6. Κάντε κλικ στη Δοκιμή. Το «Το TMDb αποδέχεται αυτό το διακριτικό» σημαίνει ότι λειτουργεί.

Το διακριτικό φυλάσσεται στο Μπρελόκ του Mac. Μόνο το Mac με τη βιβλιοθήκη το χρησιμοποιεί· οι άλλες συσκευές σας λαμβάνουν τους ηθοποιούς και τα στοιχεία από εκείνο το Mac. Οι σειρές που έχουν ήδη αναζητηθεί λαμβάνουν τους ηθοποιούς και τους συντελεστές του TMDb την επόμενη φορά που ανοίγει η σελίδα τους. Αν κλείσετε τις Ρυθμίσεις χωρίς να δοκιμάσετε ένα νέο διακριτικό, δοκιμάζεται τότε και ενημερώνεστε αν το TMDb το απορρίψει.

Σημείωση: Αυτό το προϊόν χρησιμοποιεί το TMDB API αλλά δεν εγκρίνεται ούτε πιστοποιείται από το TMDB.

Μετάφραση: ένα κλειδί Google

Οι τίτλοι και οι περιγραφές των επεισοδίων μεταφράζονται στη γλώσσα κάθε συσκευής σε αυτό το Mac, δωρεάν, με τη λειτουργία μετάφρασης της Apple. Αυτή δεν μπορεί να μεταφράσει στα ελληνικά, τσεχικά, ουγγρικά, ρουμανικά, περσικά, ούρντου ή μπενγκάλι. Για αυτές τις γλώσσες, προσθέστε το δικό σας κλειδί Google Cloud Translation API. Χρειάζεται μόνο στο Mac με τη βιβλιοθήκη, όχι στις συσκευές που την προβάλλουν. Οι πρώτοι 500.000 χαρακτήρες κάθε μήνα είναι δωρεάν, και κάθε κείμενο μεταφράζεται μόνο μία φορά.

  1. Μεταβείτε στο console.cloud.google.com και συνδεθείτε με τον λογαριασμό σας Google.
  2. Δημιουργήστε ένα έργο: κάντε κλικ στο μενού έργων στο πάνω μέρος, μετά στο New Project, και δώστε του ένα όνομα, π.χ. «TV Library Viewer».
  3. Ενεργοποιήστε τη χρέωση: στο μενού ☰, επιλέξτε Billing και συνδέστε έναν λογαριασμό χρέωσης. Η Google τον ζητά ακόμη και για δωρεάν χρήση. Για ασφάλεια, προσθέστε έναν προϋπολογισμό, π.χ. 1 $, στην ενότητα Budgets & alerts.
  4. Επιλέξτε ☰ › APIs & Services › Library, αναζητήστε το Cloud Translation API και κάντε κλικ στο Enable.
  5. Επιλέξτε ☰ › APIs & Services › Credentials, μετά Create credentials › API key, και αντιγράψτε το κλειδί (ξεκινά με «AIza»).
  6. Συνιστάται: κάντε κλικ στο όνομα του κλειδιού, επιλέξτε Restrict key στην ενότητα API restrictions, επιλέξτε το Cloud Translation API και κάντε κλικ στο Save, ώστε το κλειδί να λειτουργεί μόνο για μετάφραση.
  7. Στο Mac με τη βιβλιοθήκη, επιλέξτε TV Library Viewer › Ρυθμίσεις, κάντε κλικ στην Αποθήκευση, επικολλήστε το κλειδί στο πεδίο Κλειδί Google Cloud Translation API και κάντε κλικ στη Δοκιμή.

Το κλειδί φυλάσσεται στην Κλειδοθήκη του Mac και χρησιμοποιείται μόνο για αυτές τις επτά γλώσσες. Μην το μοιράζεστε: ό,τι μεταφράζεται με αυτό χρεώνεται στον λογαριασμό σας Google.

Κρυφές μνήμες

Οι εικόνες και οι βιβλιοθήκες που αυτό το Mac έχει προβάλει από άλλα Mac. Οι κρυφές μνήμες δημιουργούνται ξανά όταν χρειάζεται, και το macOS τις αδειάζει όταν ο χώρος δεν επαρκεί.
