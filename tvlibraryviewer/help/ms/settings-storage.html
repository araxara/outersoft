Pelakon dan krew rancangan dicari di TVmaze dan TMDb pada kali pertama halamannya dibuka, di sini atau pada mana-mana peranti. Butiran orang diambil setiap kali anda membukanya, jadi ia tidak pernah lapuk, dan tidak disimpan. Klik Tunjukkan dalam Finder untuk melihat fail pangkalan data.

Butiran Pelakon dan Krew: token TMDb

TVmaze tidak memerlukan sebarang persediaan. TMDb (The Movie Database) menambah pengarah dan penulis skrip, pelakon yang tiada dalam TVmaze, dan biografi, selalunya dalam bahasa anda. Ia memerlukan token anda sendiri: TMDb memberikannya secara percuma kepada sesiapa sahaja yang mempunyai akaun, untuk kegunaan peribadi dan bukan komersial. TV Library Viewer tidak disertakan dengan token.

  1. Buat akaun percuma di themoviedb.org, dan daftar masuk.
  2. Klik ikon akaun anda, pilih Settings, kemudian klik API.
  3. Mohon kunci API: pilih Developer, terima syarat dan terangkan kegunaan anda sebagai peribadi dan bukan komersial (contohnya, "Show cast and biographies in my own TV library app").
  4. Apabila kunci sedia, salin API Read Access Token (yang panjang, bukan API Key yang lebih pendek).
  5. Pada Mac yang mempunyai pustaka, pilih TV Library Viewer › Tetapan, klik Storan, dan tampalkannya ke dalam API Read Access Token TMDb.
  6. Klik Uji. "TMDb menerima token ini" bermakna ia berfungsi.

Token disimpan dalam Rantaian Kunci Mac. Hanya Mac yang mempunyai pustaka menggunakannya; peranti anda yang lain mendapat pelakon dan butiran daripada Mac itu. Rancangan yang sudah dicari akan mendapat pelakon dan krew TMDb pada kali seterusnya halamannya dibuka. Jika anda menutup Tetapan tanpa menguji token baharu, ia diuji pada masa itu, dan anda akan dimaklumkan jika TMDb menolaknya.

Nota: Produk ini menggunakan API TMDB tetapi tidak disokong atau diperakui oleh TMDB.

Terjemahan: kunci Google

Tajuk dan penerangan episod diterjemahkan ke dalam bahasa setiap peranti pada Mac ini, secara percuma, dengan Terjemahan Apple. Ia tidak dapat menterjemah ke dalam bahasa Greek, Czech, Hungary, Romania, Parsi, Urdu atau Benggali. Untuk bahasa tersebut, tambahkan kunci Google Cloud Translation API anda sendiri. Hanya Mac yang mempunyai pustaka memerlukannya; peranti yang melihat pustaka tidak memerlukannya. 500,000 aksara pertama setiap bulan adalah percuma, dan setiap teks diterjemahkan sekali sahaja.

  1. Pergi ke console.cloud.google.com dan daftar masuk dengan akaun Google anda.
  2. Cipta projek: klik menu projek di bahagian atas, kemudian New Project, dan berikan nama seperti "TV Library Viewer".
  3. Hidupkan pengebilan: dalam menu ☰, pilih Billing dan pautkan akaun pengebilan. Google memerlukannya walaupun untuk penggunaan percuma. Untuk keselamatan, tambahkan bajet, seperti US$1, di bawah Budgets & alerts.
  4. Pilih ☰ › APIs & Services › Library, cari Cloud Translation API, dan klik Enable.
  5. Pilih ☰ › APIs & Services › Credentials, kemudian Create credentials › API key, dan salin kunci itu (ia bermula dengan "AIza").
  6. Disyorkan: klik nama kunci, pilih Restrict key di bawah API restrictions, tandakan Cloud Translation API, dan klik Save, supaya kunci hanya berfungsi untuk terjemahan.
  7. Pada Mac yang mempunyai pustaka, pilih TV Library Viewer › Tetapan, klik Storan, tampal kunci ke dalam Kunci Google Cloud Translation API, dan klik Uji.

Kunci disimpan dalam Rantaian Kunci Mac dan hanya digunakan untuk tujuh bahasa tersebut. Jangan kongsi kunci ini: apa-apa yang diterjemahkan dengannya akan dibilkan kepada akaun Google anda.

Cache

Gambar, dan pustaka yang telah dilihat oleh Mac ini daripada Mac lain. Cache dibuat semula apabila diperlukan, dan macOS mengosongkannya apabila ruang hampir habis.
