ComandoO que faz
Abrir biblioteca… ⌘OAbre outra biblioteca do app TV neste Mac: um pacote .tvlibrary ou o arquivo Library.tvdb dentro de um.
Conectar a uma biblioteca compartilhada… ⌘KAbre uma biblioteca que outro Mac compartilha: nesta rede, via SSH ou em um endereço. Consulte Conectar a uma biblioteca compartilhada.
Conta…A sua conta na biblioteca compartilhada que você está vendo: as estatísticas, os dispositivos em que ela é usada e a alteração da senha.
Iniciar sessão com uma conta…
Iniciar sessão com outra conta…		Inicia sessão na biblioteca compartilhada com uma conta, para que o que você assiste seja só seu.
Trocar de bibliotecaVolta para a Biblioteca deste Mac ou para uma biblioteca compartilhada que você já usou.
Atualizar biblioteca ⌘RLê a biblioteca novamente. Normalmente ela se atualiza sozinha, logo depois que o app TV salva uma alteração.
