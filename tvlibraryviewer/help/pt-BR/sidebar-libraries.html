Alternar entre bibliotecas

Mac, iPad e iPhone. Na Apple TV: Bibliotecas.

A seção Bibliotecas compartilhadas da barra lateral lista as bibliotecas que você já usou. Um visto marca a que está sendo exibida agora.

  • Clique em uma biblioteca para passar para ela. No Mac, Biblioteca deste Mac volta para a biblioteca do próprio Mac.
  • Clique em uma biblioteca com a tecla Control pressionada (ou toque nela e mantenha o dedo) para Renomear… ou Esquecer. Uma biblioteca renomeada mantém o nome que você deu; deixe o nome em branco para usar o nome do próprio Mac.
  • Conectar a uma biblioteca compartilhada… adiciona outra.

O app reabre a última biblioteca que você usou.
