O elenco e a equipe de uma série são buscados no TVmaze e no TMDb na primeira vez que a página dela é aberta, aqui ou em qualquer dispositivo. Os detalhes das pessoas são obtidos sempre que você os abre, por isso nunca estão desatualizados, e não são armazenados. Clique em Mostrar no Finder para ver o arquivo do banco de dados.

Detalhes do elenco e da equipe: um token do TMDb

O TVmaze não precisa de nenhuma configuração. O TMDb (The Movie Database) acrescenta diretores e roteiristas, atores que o TVmaze não tem e biografias, muitas vezes no seu idioma. Ele precisa de um token próprio: o TMDb fornece um gratuitamente a qualquer pessoa com conta, para uso pessoal e não comercial. O TV Library Viewer não vem com um.

  1. Crie uma conta gratuita em themoviedb.org e inicie sessão.
  2. Clique no ícone da sua conta, escolha Settings e clique em API.
  3. Solicite uma chave de API: escolha Developer, aceite os termos e descreva o seu uso como pessoal e não comercial (por exemplo, "Mostrar elenco e biografias no meu próprio app de biblioteca de TV").
  4. Quando a chave estiver pronta, copie o API Read Access Token (o longo, não a API Key mais curta).
  5. No Mac com a biblioteca, escolha TV Library Viewer › Ajustes, clique em Armazenamento e cole-o em API Read Access Token do TMDb.
  6. Clique em Testar. "O TMDb aceita este token." significa que funciona.

O token fica guardado nas Chaves do Mac. Somente o Mac com a biblioteca o usa; os seus outros dispositivos recebem o elenco e os detalhes desse Mac. As séries já buscadas recebem o elenco e a equipe do TMDb na próxima vez que a página delas for aberta. Se você fechar os Ajustes sem testar um novo token, ele é testado nesse momento, e você é avisado se o TMDb o recusar.

Nota: Este produto usa a API do TMDB, mas não é endossado nem certificado pelo TMDB.

Tradução: uma chave do Google

Os títulos e as descrições dos episódios são traduzidos para o idioma de cada dispositivo neste Mac, de graça, com a tradução da Apple. Ela não traduz para grego, tcheco, húngaro, romeno, persa, urdu ou bengali. Para esses idiomas, adicione a sua própria chave da Google Cloud Translation API. Só o Mac com a biblioteca precisa de uma; os dispositivos que a visualizam, não. Os primeiros 500.000 caracteres de cada mês são gratuitos, e cada texto é traduzido uma única vez.

  1. Acesse console.cloud.google.com e inicie sessão com a sua conta do Google.
  2. Crie um projeto: clique no menu de projetos no topo, depois em New Project, e dê a ele um nome como "TV Library Viewer".
  3. Ative o faturamento: no menu ☰, escolha Billing e vincule uma conta de faturamento. O Google exige uma mesmo para uso gratuito. Por segurança, adicione um orçamento, como US$ 1, em Budgets & alerts.
  4. Escolha ☰ › APIs & Services › Library, pesquise Cloud Translation API e clique em Enable.
  5. Escolha ☰ › APIs & Services › Credentials, depois Create credentials › API key, e copie a chave (ela começa com "AIza").
  6. Recomendado: clique no nome da chave, escolha Restrict key em API restrictions, marque Cloud Translation API e clique em Save, para que a chave funcione só para tradução.
  7. No Mac com a biblioteca, escolha TV Library Viewer › Ajustes, clique em Armazenamento, cole a chave em Chave da Google Cloud Translation API e clique em Testar.

A chave fica guardada nas Chaves do Mac e é usada só para esses sete idiomas. Não a compartilhe: tudo o que for traduzido com ela é cobrado na sua conta do Google.

Caches

As imagens e as bibliotecas que este Mac exibiu a partir de outros Macs. Os caches são recriados quando necessário, e o macOS os esvazia quando fica sem espaço.
