Baza danych TV Library Viewer

Własna baza danych TV Library Viewer na tym Macu, współdzielona ze wszystkimi urządzeniami, które wyświetlają bibliotekę.

CzęśćCo zawiera
Informacje o serialachPełne opisy podane przez AppleScript oraz obsadę każdego serialu: nazwiska aktorów i ich role.
TłumaczeniaTytuły i opisy odcinków przetłumaczone na języki ustawione w aplikacjach.
Obsada i ekipaJedno małe zdjęcie każdej osoby oraz adresy jej stron w TVmaze i TMDb.
Konta i oglądanieKonta, oglądanie wszystkich kont poza głównym oraz dzienniki kont.
Struktura bazy danych i wolne miejsceWłasne rekordy SQLite i miejsce, które ponownie wykorzystuje.
Ostatnie zmianyZmiany jeszcze niewłączone do bazy danych. Robi to ona od czasu do czasu.

Obsada i ekipa serialu są wyszukiwane w TVmaze i TMDb przy pierwszym otwarciu jego strony, tutaj lub na dowolnym urządzeniu. Szczegóły osób są pobierane przy każdym ich otwarciu, więc nigdy nie są nieaktualne, i nie są przechowywane. Kliknij Pokaż w Finderze, aby zobaczyć plik bazy danych.

Szczegóły obsady i ekipy: token TMDb

TVmaze nie wymaga konfiguracji. TMDb (The Movie Database) dodaje reżyserów i scenarzystów, aktorów, których nie ma w TVmaze, oraz biografie, często w Twoim języku. Wymaga własnego tokenu: TMDb udostępnia go bezpłatnie każdemu, kto ma konto, do użytku osobistego, niekomercyjnego. TV Library Viewer nie zawiera tokenu.

  1. Utwórz bezpłatne konto w themoviedb.org i zaloguj się.
  2. Kliknij ikonę konta, wybierz Settings, a następnie kliknij API.
  3. Poproś o klucz API: wybierz Developer, zaakceptuj warunki i opisz zastosowanie jako osobiste i niekomercyjne (na przykład „Show cast and biographies in my own TV library app”).
  4. Gdy klucz będzie gotowy, skopiuj API Read Access Token (długi, a nie krótszy API Key).
  5. Na Macu z biblioteką wybierz TV Library Viewer › Ustawienia, kliknij Pamięć i wklej go w pole API Read Access Token z TMDb.
  6. Kliknij Testuj. Komunikat „TMDb akceptuje ten token” oznacza, że działa.

Token jest przechowywany w pęku kluczy Maca. Używa go tylko Mac z biblioteką; inne Twoje urządzenia otrzymują obsadę i szczegóły z tego Maca. Seriale już wyszukane otrzymają obsadę i ekipę z TMDb przy następnym otwarciu ich strony. Jeśli zamkniesz Ustawienia bez przetestowania nowego tokenu, zostanie on wtedy przetestowany, a Ty dowiesz się, jeśli TMDb go odrzuci.

Uwaga: Ten produkt korzysta z TMDB API, ale nie jest wspierany ani certyfikowany przez TMDB.

Tłumaczenie: klucz Google

Tytuły i opisy odcinków są tłumaczone na język każdego urządzenia na tym Macu, bezpłatnie, za pomocą tłumaczenia Apple. Nie potrafi ono tłumaczyć na grecki, czeski, węgierski, rumuński, perski, urdu ani bengalski. Dla tych języków dodaj własny klucz Google Cloud Translation API. Potrzebuje go tylko Mac z biblioteką, a nie urządzenia, które ją przeglądają. Pierwsze 500 000 znaków w każdym miesiącu jest bezpłatne, a każdy tekst jest tłumaczony tylko raz.

  1. Przejdź do console.cloud.google.com i zaloguj się na swoje konto Google.
  2. Utwórz projekt: kliknij menu projektów u góry, a następnie New Project, i nadaj mu nazwę, np. „TV Library Viewer”.
  3. Włącz płatności: w menu ☰ wybierz Billing i połącz konto rozliczeniowe. Google wymaga go nawet przy bezpłatnym korzystaniu. Dla bezpieczeństwa dodaj budżet, np. 1 USD, w sekcji Budgets & alerts.
  4. Wybierz ☰ › APIs & Services › Library, wyszukaj Cloud Translation API i kliknij Enable.
  5. Wybierz ☰ › APIs & Services › Credentials, a następnie Create credentials › API key, i skopiuj klucz (zaczyna się od „AIza”).
  6. Zalecane: kliknij nazwę klucza, w sekcji API restrictions wybierz Restrict key, zaznacz Cloud Translation API i kliknij Save, aby klucz działał tylko do tłumaczenia.
  7. Na Macu z biblioteką wybierz TV Library Viewer › Ustawienia, kliknij Pamięć, wklej klucz w polu Klucz Google Cloud Translation API i kliknij Testuj.

Klucz jest przechowywany w pęku kluczy Maca i używany tylko dla tych siedmiu języków. Nie udostępniaj go innym: wszystko, co zostanie nim przetłumaczone, obciąża Twoje konto Google.
