En series rollista och team slås upp på TVmaze och TMDb första gången dess sida öppnas, här eller på någon annan enhet. Uppgifter om personer hämtas varje gång du öppnar dem, så att de aldrig är inaktuella, och lagras inte. Klicka på Visa i Finder för att se databasfilen.

Detaljer om rollista och team: en TMDb-token

TVmaze behöver ingen inställning. TMDb (The Movie Database) lägger till regissörer och manusförfattare, skådespelare som TVmaze saknar, och biografier, ofta på ditt språk. Det kräver en egen token: TMDb ger en gratis till alla med ett konto, för personligt, icke-kommersiellt bruk. TV Library Viewer levereras inte med någon.

  1. Skapa ett gratiskonto på themoviedb.org och logga in.
  2. Klicka på din kontosymbol, välj Settings och klicka sedan på API.
  3. Ansök om en API-nyckel: välj Developer, godkänn villkoren och beskriv din användning som personlig och icke-kommersiell (till exempel "Show cast and biographies in my own TV library app").
  4. När nyckeln är klar kopierar du API Read Access Token (den långa, inte den kortare API Key).
  5. På den Mac som har biblioteket väljer du TV Library Viewer › Inställningar, klickar på Lagring och klistrar in den i TMDb API Read Access Token.
  6. Klicka på Testa. "TMDb godkänner denna token." betyder att den fungerar.

Token sparas i datorns nyckelring. Bara den Mac som har biblioteket använder den; dina andra enheter får rollista och detaljer från den datorn. Serier som redan slagits upp får TMDb:s rollista och team nästa gång deras sida öppnas. Om du stänger Inställningar utan att testa en ny token testas den då, och du får veta om TMDb avvisar den.

Obs! Den här produkten använder TMDB API men är inte godkänd eller certifierad av TMDB.

Översättning: en Google-nyckel

Avsnittstitlar och beskrivningar översätts till varje enhets språk på den här Macen, gratis, med Apples översättning. Den kan inte översätta till grekiska, tjeckiska, ungerska, rumänska, persiska, urdu eller bengali. För de språken lägger du till en egen Google Cloud Translation API key. Bara Macen med biblioteket behöver en; enheterna som visar det gör det inte. De första 500 000 tecknen varje månad är gratis, och varje text översätts bara en gång.

  1. Gå till console.cloud.google.com och logga in med ditt Google-konto.
  2. Skapa ett projekt: klicka på projektmenyn högst upp, sedan på New Project, och ge det ett namn, till exempel "TV Library Viewer".
  3. Aktivera fakturering: välj Billing i menyn ☰ och koppla ett faktureringskonto. Google kräver ett även för gratis användning. Lägg för säkerhets skull till en budget, till exempel 1 dollar, under Budgets & alerts.
  4. Välj ☰ › APIs & Services › Library, sök efter Cloud Translation API och klicka på Enable.
  5. Välj ☰ › APIs & Services › Credentials, sedan Create credentials › API key, och kopiera nyckeln (den börjar med "AIza").
  6. Rekommenderas: klicka på nyckelns namn, välj Restrict key under API restrictions, markera Cloud Translation API och klicka på Save, så att nyckeln bara fungerar för översättning.
  7. Välj TV Library Viewer › Inställningar på Macen med biblioteket, klicka på Lagring, klistra in nyckeln i Nyckel för Google Cloud Translation API och klicka på Testa.

Nyckeln sparas i Macens nyckelring och används bara för de sju språken. Dela den inte med någon: allt som översätts med den debiteras ditt Google-konto.

Cacheminnen

Bilder, och biblioteken som den här datorn har visat från andra Mac-datorer. Cacheminnen skapas på nytt vid behov, och macOS tömmer dem när det börjar bli ont om utrymme.
