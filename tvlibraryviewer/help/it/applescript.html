AppleScript

TV Library Viewer si può controllare con gli script, ad esempio da uno script che importa episodi. Apri il suo dizionario in Script Editor (File › Apri dizionario…) per i dettagli.

ComandoCosa fa
add episodeAggiunge un file video alla libreria dell’app TV (o lo trova lì) con serie, stagione, episodio, titolo, genere e descrizioni, e ne restituisce l’ID persistente.
update episodeModifica i dati di un episodio.
remove episodeRimuove un episodio dalla libreria. Il file resta.
refresh libraryRilegge la libreria.
create account, change account password, delete account, account names, account logGestiscono gli account.

Le descrizioni lunghe impostate in questo modo vengono conservate nel database di TV Library Viewer e ripristinate quando l’app TV le dimentica.
