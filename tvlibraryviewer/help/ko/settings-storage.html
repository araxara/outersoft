이 Mac의 TV 보관함

TV 앱 보관함에 있는 프로그램과 에피소드의 수 및 해당 데이터베이스의 크기입니다. 비디오 파일은 포함되지 않습니다.

TV Library Viewer 데이터베이스

이 Mac에 있는 TV Library Viewer 자체 데이터베이스로, 보관함을 보는 모든 기기와 공유됩니다.

항목내용
프로그램 정보AppleScript로 지정한 전체 설명과 각 프로그램의 출연진(배우의 이름과 배역).
번역앱에 설정된 언어로 번역된 에피소드 제목과 설명.
출연진 및 제작진사람마다 작은 사진 한 장과 TVmaze 및 TMDb에 있는 해당 인물 페이지의 주소.
계정 및 시청계정, 주 계정을 제외한 모든 계정의 시청 기록 및 계정의 로그.
데이터베이스 구조 및 여유 공간SQLite 자체의 기록과 다시 사용하는 공간.
최근 변경 사항아직 데이터베이스에 반영되지 않은 변경 사항. 반영은 때때로 자동으로 이루어집니다.

프로그램의 출연진과 제작진은 여기 또는 다른 기기에서 해당 프로그램 페이지를 처음 열 때 TVmaze 및 TMDb에서 찾습니다. 인물의 세부사항은 열 때마다 가져오므로 항상 최신 상태이며 저장되지 않습니다. 데이터베이스 파일을 보려면 Finder에서 보기를 클릭하십시오.

출연진 및 제작진 정보: TMDb 토큰

TVmaze는 설정할 것이 없습니다. TMDb(The Movie Database)는 감독과 각본가, TVmaze에 없는 배우, 그리고 약력을 추가하며, 대개 사용자의 언어로 제공됩니다. TMDb를 사용하려면 자신의 토큰이 필요합니다. TMDb는 계정이 있는 누구에게나 개인적이고 비상업적인 용도로 토큰을 무료로 제공합니다. TV Library Viewer에는 토큰이 포함되어 있지 않습니다.

  1. themoviedb.org에서 무료 계정을 만들고 로그인합니다.
  2. 계정 아이콘을 클릭하고 Settings를 선택한 다음 API를 클릭합니다.
  3. API 키를 요청합니다. Developer를 선택하고, 약관에 동의한 다음, 용도를 개인적이고 비상업적인 것으로 설명합니다(예: '내 TV 보관함 앱에서 출연진과 약력 표시').
  4. 키가 준비되면 API Read Access Token(짧은 API Key가 아닌 긴 것)을 복사합니다.
  5. 보관함이 있는 Mac에서 TV Library Viewer › 설정을 선택하고 저장 공간을 클릭한 다음 TMDb API Read Access Token에 붙여넣습니다.
  6. 테스트를 클릭합니다. 'TMDb에서 이 토큰을 허용합니다.'라고 표시되면 작동하는 것입니다.

토큰은 Mac의 키체인에 보관됩니다. 토큰은 보관함이 있는 Mac만 사용하며, 다른 기기는 해당 Mac에서 출연진과 세부사항을 받습니다. 이미 찾은 프로그램은 다음에 해당 페이지를 열 때 TMDb의 출연진 및 제작진을 가져옵니다. 새 토큰을 테스트하지 않고 설정을 닫으면 그때 테스트되며, TMDb가 거부하면 알려 줍니다.

참고: 이 제품은 TMDB API를 사용하지만 TMDB의 보증 또는 인증을 받지 않았습니다.

번역: Google 키

에피소드 제목과 설명은 Apple의 번역 기능으로 이 Mac에서 각 기기의 언어로 무료로 번역됩니다. 하지만 그리스어, 체코어, 헝가리어, 루마니아어, 페르시아어, 우르두어, 벵골어로는 번역할 수 없습니다. 이러한 언어에는 자신의 Google Cloud Translation API 키를 추가하십시오. 키는 보관함이 있는 Mac에만 필요하며, 보관함을 보는 기기에는 필요하지 않습니다. 매달 처음 500,000자는 무료이며, 각 텍스트는 한 번만 번역됩니다.

  1. console.cloud.google.com으로 이동하여 Google 계정으로 로그인합니다.
  2. 프로젝트를 만듭니다. 상단의 프로젝트 메뉴를 클릭한 다음 New Project를 클릭하고 'TV Library Viewer'와 같은 이름을 지정합니다.
  3. 결제를 켭니다. 메뉴 ☰에서 Billing을 선택하고 결제 계정을 연결합니다. Google은 무료로 사용할 때도 결제 계정을 요구합니다. 안전을 위해 Budgets & alerts에서 $1와 같은 예산을 추가하십시오.
  4. ☰ › APIs & Services › Library를 선택하고 Cloud Translation API를 검색한 다음 Enable을 클릭합니다.
  5. ☰ › APIs & Services › Credentials를 선택한 다음 Create credentials › API key를 선택하고 키('AIza'로 시작함)를 복사합니다.
  6. 권장: 키 이름을 클릭하고 API restrictions에서 Restrict key를 선택한 다음 Cloud Translation API를 체크하고 Save를 클릭하면, 키가 번역에만 사용됩니다.
  7. 보관함이 있는 Mac에서 TV Library Viewer › 설정을 선택하고 저장 공간을 클릭한 다음, Google Cloud Translation API 키에 키를 붙여넣고 테스트를 클릭합니다.

키는 Mac의 키체인에 보관되며 이 일곱 가지 언어에만 사용됩니다. 키를 공유하지 마십시오. 키로 번역한 모든 내용은 사용자의 Google 계정으로 청구됩니다.

캐시
