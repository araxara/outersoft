TV Library Viewer Help › Getting Started

Connect to a shared library

Each device connects once. After that it reopens the same library by itself.

Open Connect to Shared Library

  • Mac: choose File › Connect to Shared Library… (⌘K).
  • iPad and iPhone: tap Connect to Shared Library… in the sidebar (⌘K with a keyboard).
  • Apple TV: the first time, TV Library connects to the first Mac on the network that shares without a password. Otherwise go to Libraries › Connect to Another Library….

Choose how to reach the Mac

This Network

Macs on the same network with sharing on are listed by name. Choose one.

Remote (SSH)

For a Mac on another network, such as another home. Type the address you use to SSH into that Mac (or any computer on its network), and the user name if it's different. TV Library Viewer logs in, finds the library on that network and connects through the SSH connection.

  • The first time, it shows the host's key to compare and confirm.
  • On a Mac, your own SSH key is used when the host accepts it; otherwise it asks for the password and keeps it in your Keychain.
  • An iPad, iPhone or Apple TV has its own key. After the first password login it offers to install that key on the host, so it doesn't need the password again.

Address

For a Mac this device can reach directly: through a VPN such as Tailscale, or a port your router forwards to it. Type the address and port (port 47100 unless it was changed), and an account name and password if the library has accounts.

Trust the library's certificate

The first connection shows the library's certificate fingerprint. Compare it with the one in Settings › Sharing on the Mac with the library, then choose Trust and Connect. From then on the device checks that certificate every time, and refuses a library whose certificate has changed.

Sign in

If the library has accounts, enter your account's name and password from that Mac. The device keeps them in its Keychain. With no accounts, leave the name empty and use the library password, if there is one.
