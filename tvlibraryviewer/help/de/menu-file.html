Menü „Ablage“

BefehlFunktion
Mediathek öffnen … ⌘OÖffnet eine andere Mediathek der TV-App auf diesem Mac: ein .tvlibrary-Paket oder die Datei Library.tvdb darin.
Mit geteilter Mediathek verbinden … ⌘KÖffnet eine Mediathek, die ein anderer Mac teilt: in diesem Netzwerk, über SSH oder unter einer Adresse. Siehe Mit einer geteilten Mediathek verbinden.
Account …Dein Account bei der geteilten Mediathek, die du gerade siehst: seine Statistiken, die Geräte, von denen aus er verwendet wird, und das Ändern seines Passworts.
Mit einem Account anmelden …
Mit anderem Account anmelden …		Meldet dich mit einem Account bei der geteilten Mediathek an, damit deine Wiedergaben dir gehören.
Mediathek wechselnKehrt zur Mediathek dieses Mac zurück oder zu einer geteilten Mediathek, die du schon verwendet hast.
Mediathek aktualisieren ⌘RLiest die Mediathek neu ein. Normalerweise aktualisiert sie sich von selbst, kurz nachdem die TV-App eine Änderung gesichert hat.
