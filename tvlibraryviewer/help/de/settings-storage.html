Besetzung und Crew einer Serie werden bei TVmaze und TMDb nachgeschlagen, wenn ihre Seite zum ersten Mal geöffnet wird, hier oder auf einem beliebigen Gerät. Angaben zu Personen werden bei jedem Öffnen abgerufen, sind also nie veraltet, und werden nicht gespeichert. Klicke auf Im Finder zeigen, um die Datenbankdatei zu sehen.

Details zu Besetzung und Crew: ein TMDb-Token

TVmaze erfordert keine Einrichtung. TMDb (The Movie Database) ergänzt Regie und Drehbuch, Schauspieler, die TVmaze nicht hat, und Biografien, oft in deiner Sprache. Dafür brauchst du ein eigenes Token: TMDb vergibt es kostenlos an alle mit Account, für die private, nicht kommerzielle Nutzung. TV Library Viewer bringt keines mit.

  1. Erstelle auf themoviedb.org einen kostenlosen Account und melde dich an.
  2. Klicke auf dein Accountsymbol, wähle Settings und klicke dann auf API.
  3. Beantrage einen API-Schlüssel: Wähle Developer, akzeptiere die Bedingungen und beschreibe deine Nutzung als privat und nicht kommerziell (zum Beispiel „Besetzung und Biografien in meiner eigenen TV-Mediathek-App anzeigen“).
  4. Wenn der Schlüssel bereit ist, kopiere das API Read Access Token (das lange, nicht den kürzeren API Key).
  5. Wähle auf dem Mac mit der Mediathek TV Library Viewer › Einstellungen, klicke auf Speicher und füge es in TMDb API Read Access Token ein.
  6. Klicke auf Testen. „TMDb akzeptiert dieses Token.“ bedeutet, dass es funktioniert.

Das Token wird im Schlüsselbund des Mac verwahrt. Nur der Mac mit der Mediathek verwendet es; deine anderen Geräte erhalten Besetzung und Details von diesem Mac. Bereits nachgeschlagene Serien erhalten die Besetzung und Crew von TMDb beim nächsten Öffnen ihrer Seite. Schließt du die Einstellungen, ohne ein neues Token zu testen, wird es dann getestet, und du erfährst es, wenn TMDb es ablehnt.

Hinweis: Dieses Produkt verwendet die TMDB-API, wird aber von TMDB weder unterstützt noch zertifiziert.

Übersetzung: ein Google-Schlüssel

Episodentitel und -beschreibungen werden auf diesem Mac kostenlos mit Apples Übersetzung in die Sprache jedes Geräts übersetzt. Ins Griechische, Tschechische, Ungarische, Rumänische, Persische, Urdu und Bengalische kann sie nicht übersetzen. Dafür fügst du einen eigenen Google Cloud Translation API key hinzu. Nur der Mac mit der Mediathek braucht einen, die Geräte, die sie ansehen, nicht. Die ersten 500.000 Zeichen pro Monat sind kostenlos, und jeder Text wird nur einmal übersetzt.

  1. Öffne console.cloud.google.com und melde dich mit deinem Google-Account an.
  2. Erstelle ein Projekt: Klicke oben auf das Projektmenü, dann auf New Project, und gib ihm einen Namen wie „TV Library Viewer“.
  3. Aktiviere die Abrechnung: Wähle im Menü ☰ Billing und verknüpfe ein Rechnungskonto. Google verlangt eines auch für die kostenlose Nutzung. Lege zur Sicherheit unter Budgets & alerts ein Budget an, zum Beispiel 1 $.
  4. Wähle ☰ › APIs & Services › Library, suche nach Cloud Translation API und klicke auf Enable.
  5. Wähle ☰ › APIs & Services › Credentials, dann Create credentials › API key, und kopiere den Schlüssel (er beginnt mit „AIza“).
  6. Empfohlen: Klicke auf den Namen des Schlüssels, wähle unter „API restrictions“ Restrict key, markiere Cloud Translation API und klicke auf Save, damit der Schlüssel nur für Übersetzungen funktioniert.
  7. Wähle auf dem Mac mit der Mediathek TV Library Viewer › Einstellungen, klicke auf Speicher, füge den Schlüssel in Google Cloud Translation API-Schlüssel ein und klicke auf Testen.

Der Schlüssel wird im Schlüsselbund des Mac gespeichert und nur für diese sieben Sprachen verwendet. Gib ihn nicht weiter: Alles, was damit übersetzt wird, wird deinem Google-Account in Rechnung gestellt.

Caches

Bilder und die Mediatheken, die dieser Mac von anderen Macs angezeigt hat. Caches werden bei Bedarf neu erstellt, und macOS leert sie, wenn der Speicherplatz knapp wird.
