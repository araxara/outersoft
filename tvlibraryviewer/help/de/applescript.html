AppleScript

TV Library Viewer lässt sich per Skript steuern, zum Beispiel von einem Skript, das Folgen importiert. Öffne sein Verzeichnis im Skripteditor (Ablage › Verzeichnis öffnen …), um die Details zu sehen.

BefehlFunktion
add episodeFügt eine Videodatei zur Mediathek der TV-App hinzu (oder findet sie dort), mit Serie, Staffel, Folge, Titel, Genre und Beschreibungen, und gibt ihre persistente ID zurück.
update episodeÄndert die Angaben einer Folge.
remove episodeEntfernt eine Folge aus der Mediathek. Die Datei bleibt erhalten.
refresh libraryLiest die Mediathek neu ein.
create account, change account password, delete account, account names, account logVerwalten Accounts.

Auf diesem Weg festgelegte lange Beschreibungen werden in der Datenbank von TV Library Viewer gesichert und wiederhergestellt, wenn die TV-App sie vergisst.
