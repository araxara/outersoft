TV Library Viewerin tietokanta

TV Library Viewerin oma tietokanta tässä Macissa, jaettuna kaikille kirjastoa katseleville laitteille.

Sarjan näyttelijät ja tekijät haetaan TVmazesta ja TMDb:stä, kun sen sivu avataan ensimmäisen kerran, täällä tai millä tahansa laitteella. Henkilöiden tiedot noudetaan aina, kun avaat ne, joten ne eivät koskaan vanhene, eikä niitä tallenneta. Osoita Näytä Finderissa, niin näet tietokantatiedoston.

Näyttelijöiden ja tekijöiden tiedot: TMDb-tunnus

TVmaze ei vaadi määrityksiä. TMDb (The Movie Database) lisää ohjaajat ja käsikirjoittajat, näyttelijät, joita TVmazessa ei ole, sekä elämäkerrat, usein omalla kielelläsi. Se vaatii oman tunnuksen: TMDb antaa sellaisen ilmaiseksi kenelle tahansa, jolla on tili, henkilökohtaiseen, ei-kaupalliseen käyttöön. TV Library Viewerin mukana ei tule tunnusta.

  1. Luo ilmainen tili osoitteessa themoviedb.org ja kirjaudu sisään.
  2. Osoita tilisi kuvaketta, valitse Settings ja osoita sitten API.
  3. Pyydä API-avain: valitse Developer, hyväksy ehdot ja kuvaile käyttösi henkilökohtaiseksi ja ei-kaupalliseksi (esimerkiksi ”Show cast and biographies in my own TV library app”).
  4. Kun avain on valmis, kopioi API Read Access Token (pitkä, ei lyhyempi API Key).
  5. Valitse Macissa, jossa kirjasto on, TV Library Viewer › Asetukset, osoita Tallennustila ja liitä tunnus kenttään TMDb API Read Access Token.
  6. Osoita Testaa. ”TMDb hyväksyy tämän tunnuksen” tarkoittaa, että se toimii.

Tunnus säilytetään Macin Avainnipussa. Vain Mac, jossa kirjasto on, käyttää sitä; muut laitteesi saavat näyttelijät ja tiedot siltä Macilta. Jo haetut sarjat saavat TMDb:n näyttelijät ja tekijät seuraavan kerran, kun niiden sivu avataan. Jos suljet Asetukset testaamatta uutta tunnusta, se testataan silloin, ja saat tiedon, jos TMDb hylkää sen.

Huomaa: Tämä tuote käyttää TMDB API:a, mutta TMDB ei ole hyväksynyt tai sertifioinut sitä.

Käännös: Google-avain

Jaksojen nimet ja kuvaukset käännetään kunkin laitteen kielelle tällä Macilla maksutta Applen käännöstoiminnolla. Se ei osaa kääntää kreikaksi, tšekiksi, unkariksi, romaniaksi, persiaksi, urduksi eikä bengaliksi. Niitä varten voit lisätä oman Google Cloud Translation API -avaimen. Avain tarvitaan vain Maciin, jossa kirjasto on, ei sitä katseleviin laitteisiin. Ensimmäiset 500 000 merkkiä kuukaudessa ovat maksuttomia, ja kukin teksti käännetään vain kerran.

  1. Siirry osoitteeseen console.cloud.google.com ja kirjaudu sisään Google-tililläsi.
  2. Luo projekti: osoita yläreunan projektivalikkoa, sitten New Project, ja anna sille nimi, esimerkiksi ”TV Library Viewer”.
  3. Ota laskutus käyttöön: valitse valikosta ☰ Billing ja yhdistä laskutustili. Google vaatii sen myös maksuttomaan käyttöön. Varmuuden vuoksi lisää budjetti, esimerkiksi 1 $, kohdassa Budgets & alerts.
  4. Valitse ☰ › APIs & Services › Library, hae Cloud Translation API ja osoita Enable.
  5. Valitse ☰ › APIs & Services › Credentials, sitten Create credentials › API key, ja kopioi avain (se alkaa merkeillä ”AIza”).
  6. Suositus: osoita avaimen nimeä, valitse Restrict key kohdassa API restrictions, valitse Cloud Translation API ja osoita Save, jotta avain toimii vain kääntämiseen.
  7. Valitse kirjaston Macilla TV Library Viewer › Asetukset, osoita Tallennustila, liitä avain kenttään Google Cloud Translation API -avain ja osoita Testaa.

Avain säilytetään Macin avainnipussa, ja sitä käytetään vain näihin seitsemään kieleen. Älä jaa sitä muille: kaikki sillä käännetty laskutetaan Google-tililtäsi.
