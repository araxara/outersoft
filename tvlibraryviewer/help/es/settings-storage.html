El reparto y el equipo de una serie se buscan en TVmaze y TMDb la primera vez que se abre su página, aquí o en cualquier dispositivo. Los datos de las personas se obtienen cada vez que las abres, así que nunca están desactualizados, y no se guardan. Haz clic en Mostrar en el Finder para ver el archivo de la base de datos.

Detalles del reparto y el equipo: un token de TMDb

TVmaze no necesita configuración. TMDb (The Movie Database) añade directores y guionistas, actores que TVmaze no tiene, y biografías, a menudo en tu idioma. Necesita un token propio: TMDb da uno gratis a cualquiera que tenga una cuenta, para uso personal y no comercial. TV Library Viewer no incluye ninguno.

  1. Crea una cuenta gratuita en themoviedb.org e inicia sesión.
  2. Haz clic en el icono de tu cuenta, elige Settings y haz clic en API.
  3. Solicita una clave de API: elige Developer, acepta las condiciones y describe tu uso como personal y no comercial (por ejemplo, “Mostrar el reparto y las biografías en mi propia app de biblioteca de TV”).
  4. Cuando la clave esté lista, copia el API Read Access Token (el largo, no la API Key, que es más corta).
  5. En el Mac que tiene la biblioteca, selecciona TV Library Viewer › Ajustes, haz clic en Almacenamiento y pégalo en API Read Access Token de TMDb.
  6. Haz clic en Probar. “TMDb acepta este token.” significa que funciona.

El token se guarda en el llavero del Mac. Solo lo usa el Mac que tiene la biblioteca; tus otros dispositivos obtienen el reparto y los detalles de ese Mac. Las series ya buscadas obtienen el reparto y el equipo de TMDb la próxima vez que se abre su página. Si cierras Ajustes sin probar un token nuevo, se prueba en ese momento, y se te avisa si TMDb lo rechaza.

Nota: Este producto usa la API de TMDB, pero TMDB no lo respalda ni lo certifica.

Traducción: una clave de Google

Los títulos y las descripciones de los episodios se traducen al idioma de cada dispositivo en este Mac, gratis, con la traducción de Apple. No puede traducir al griego, checo, húngaro, rumano, persa, urdu ni bengalí. Para esos idiomas, añade tu propia clave de Google Cloud Translation API. Solo la necesita el Mac con la biblioteca; los dispositivos que la ven, no. Los primeros 500.000 caracteres de cada mes son gratis, y cada texto se traduce una sola vez.

  1. Ve a console.cloud.google.com e inicia sesión con tu cuenta de Google.
  2. Crea un proyecto: haz clic en el menú de proyectos de la parte superior, luego en New Project, y ponle un nombre como “TV Library Viewer”.
  3. Activa la facturación: en el menú ☰, elige Billing y vincula una cuenta de facturación. Google pide una incluso para el uso gratuito. Por seguridad, añade un presupuesto, por ejemplo de 1 $, en Budgets & alerts.
  4. Elige ☰ › APIs & Services › Library, busca Cloud Translation API y haz clic en Enable.
  5. Elige ☰ › APIs & Services › Credentials, luego Create credentials › API key, y copia la clave (empieza por “AIza”).
  6. Recomendado: haz clic en el nombre de la clave, elige Restrict key en API restrictions, marca Cloud Translation API y haz clic en Save, para que la clave solo sirva para traducir.
  7. En el Mac con la biblioteca, elige TV Library Viewer › Ajustes, haz clic en Almacenamiento, pega la clave en Clave de Google Cloud Translation API y haz clic en Probar.

La clave se guarda en el llavero del Mac y solo se usa para esos siete idiomas. No la compartas: todo lo que se traduzca con ella se cobra a tu cuenta de Google.
