คลัง TV ของ Mac เครื่องนี้

จำนวนรายการและตอนในคลังของแอป TV และขนาดฐานข้อมูลของคลัง ไม่นับรวม ไฟล์วิดีโอ

ฐานข้อมูล TV Library Viewer

ฐานข้อมูลของ TV Library Viewer เองบน Mac เครื่องนี้ ซึ่งแชร์กับอุปกรณ์ทุกเครื่องที่ใช้ดูคลัง

ส่วนสิ่งที่เก็บ
ข้อมูลรายการคำอธิบายฉบับเต็มที่ใส่ผ่าน AppleScript และนักแสดงของแต่ละ รายการ: ชื่อนักแสดงและบทบาท
คำแปลชื่อและคำอธิบายของตอนที่แปลเป็นภาษาที่ตั้งไว้ในแอป
นักแสดงและทีมงานรูปขนาดเล็กหนึ่งรูปสำหรับแต่ละคน และที่อยู่หน้าเพจของบุคคลนั้น บน TVmaze และ TMDb
บัญชีและการดูบัญชี ประวัติการดูของทุกบัญชียกเว้น บัญชีหลัก และบันทึกของบัญชี
โครงสร้างฐานข้อมูลและพื้นที่ว่างระเบียนของ SQLite เอง และพื้นที่ที่ SQLite นำกลับมาใช้ใหม่
การเปลี่ยนแปลงล่าสุดการเปลี่ยนแปลงที่ยังไม่ได้รวมเข้าในฐานข้อมูล ซึ่งจะรวมเป็น ระยะๆ

นักแสดงและทีมงานของรายการจะค้นหาบน TVmaze และ TMDb ในครั้งแรกที่เปิดหน้าของรายการ ไม่ว่าจะที่นี่หรือ บนอุปกรณ์ใดก็ตาม รายละเอียดของบุคคลจะดึงมาใหม่ทุกครั้งที่คุณเปิด จึงไม่ล้าสมัย และไม่ได้ถูกจัดเก็บ คลิก แสดงใน Finder เพื่อดูไฟล์ฐานข้อมูล

รายละเอียดนักแสดงและทีมงาน: โทเค็น TMDb

TVmaze ไม่ต้องตั้งค่าใดๆ TMDb (The Movie Database) จะเพิ่มผู้กำกับและผู้เขียนบท นักแสดง ที่ TVmaze ไม่มี และประวัติ ซึ่งมักเป็นภาษาของคุณ TMDb ต้องใช้โทเค็นของคุณเอง: TMDb ให้ฟรีแก่ทุกคนที่มีบัญชี สำหรับการใช้งานส่วนตัวที่ไม่ใช่เชิงพาณิชย์ TV Library Viewer ไม่ได้มีโทเค็นมาให้

  1. สร้างบัญชีฟรีที่ themoviedb.org แล้วลงชื่อเข้า
  2. คลิกไอคอนบัญชีของคุณ เลือก Settings แล้วคลิก API
  3. ขอคีย์ API: เลือก Developer ยอมรับข้อกำหนด และอธิบายการใช้งานของคุณว่าเป็นการใช้งานส่วนตัว และไม่ใช่เชิงพาณิชย์ (เช่น "Show cast and biographies in my own TV library app")
  4. เมื่อคีย์พร้อมแล้ว ให้คัดลอก API Read Access Token (ตัวที่ยาว ไม่ใช่ API Key ที่สั้นกว่า)
  5. บน Mac ที่มีคลัง ให้เลือก TV Library Viewer › การตั้งค่า คลิก ที่เก็บข้อมูล แล้ว วางลงใน TMDb API Read Access Token
  6. คลิก ทดสอบ "TMDb ยอมรับโทเค็นนี้" หมายความว่าใช้งานได้

โทเค็นจะเก็บไว้ในพวงกุญแจของ Mac มีเพียง Mac ที่มีคลังเท่านั้นที่ใช้โทเค็น อุปกรณ์ อื่นของคุณจะได้รับนักแสดงและรายละเอียดจาก Mac เครื่องนั้น รายการที่ค้นหาไปแล้วจะได้รับนักแสดงและทีมงานจาก TMDb ในครั้งถัดไปที่เปิดหน้าของรายการ หากคุณปิดการตั้งค่าโดยไม่ได้ทดสอบโทเค็นใหม่ โทเค็นจะได้รับการทดสอบในตอนนั้น และคุณจะได้รับแจ้งหาก TMDb ปฏิเสธ

หมายเหตุ: ผลิตภัณฑ์นี้ใช้ API ของ TMDB แต่ไม่ได้รับการรับรองหรือการรับประกันจาก TMDB

การแปล: คีย์ Google

ชื่อและคำอธิบายของตอนจะได้รับการแปลเป็นภาษาของแต่ละอุปกรณ์บน Mac เครื่องนี้ฟรี ด้วยการแปลของ Apple แต่ไม่สามารถแปลเป็นภาษากรีก เช็ก ฮังการี โรมาเนีย เปอร์เซีย อูรดู หรือเบงกาลีได้ สำหรับภาษาเหล่านั้น ให้เพิ่มคีย์ Google Cloud Translation API ของคุณเอง มีเพียง Mac ที่มีคลัง เท่านั้นที่ต้องใช้คีย์ อุปกรณ์ที่ดูคลังไม่ต้องใช้ 500,000 อักขระแรกของทุกเดือนใช้ได้ฟรี และข้อความแต่ละรายการ จะได้รับการแปลเพียงครั้งเดียว

  1. ไปที่ console.cloud.google.com แล้วลงชื่อเข้าด้วยบัญชี Google ของคุณ
  2. สร้างโปรเจกต์: คลิกเมนูโปรเจกต์ที่ด้านบน แล้วคลิก New Project และตั้งชื่อ เช่น "TV Library Viewer"
  3. เปิดการเรียกเก็บเงิน: ในเมนู ☰ ให้เลือก Billing แล้วเชื่อมโยงบัญชีสำหรับเรียกเก็บเงิน Google ต้องการบัญชีนี้ แม้จะใช้งานฟรีก็ตาม เพื่อความปลอดภัย ให้เพิ่มงบประมาณ เช่น 1 ดอลลาร์ ภายใต้ Budgets & alerts
  4. เลือก ☰ › APIs & Services › Library ค้นหา Cloud Translation API แล้วคลิก Enable
  5. เลือก ☰ › APIs & Services › Credentials แล้วเลือก Create credentials › API key และ คัดลอกคีย์ (ขึ้นต้นด้วย "AIza")
  6. แนะนำ: คลิกชื่อของคีย์ เลือก Restrict key ภายใต้ API restrictions ทำเครื่องหมาย Cloud Translation API แล้วคลิก Save เพื่อให้คีย์ใช้ได้กับการแปลเท่านั้น
  7. บน Mac ที่มีคลัง ให้เลือก TV Library Viewer › การตั้งค่า คลิก ที่เก็บข้อมูล วางคีย์ลงใน คีย์ Google Cloud Translation API แล้วคลิก ทดสอบ

คีย์จะเก็บไว้ในพวงกุญแจของ Mac และใช้สำหรับเจ็ดภาษานั้นเท่านั้น อย่าแชร์คีย์นี้ กับผู้อื่น ทุกอย่างที่แปลด้วยคีย์นี้จะเรียกเก็บเงินจากบัญชี Google ของคุณ

แคช

ภาพ และคลังที่ Mac เครื่องนี้เคยดูจาก Mac เครื่องอื่น แคชจะสร้างขึ้นใหม่เมื่อจำเป็น และ macOS จะล้างแคชเมื่อพื้นที่ใกล้เต็ม
