วิธีใช้ TV Library Viewer › ข้อมูลอ้างอิง

AppleScript

TV Library Viewer สามารถควบคุมด้วยสคริปต์ได้ เช่น จากสคริปต์ที่นำเข้าตอนต่างๆ เปิดพจนานุกรมของแอปในตัวแก้ไขสคริปต์ (ไฟล์ › เปิดพจนานุกรม…) เพื่อดูรายละเอียด

คำสั่งสิ่งที่ทำ
add episodeเพิ่มไฟล์วิดีโอลงในคลังของแอป TV (หรือค้นหาไฟล์นั้นในคลัง) พร้อม รายการ ซีซั่น ตอน ชื่อเรื่อง ประเภท และคำอธิบาย แล้วส่งคืน ID ถาวรของไฟล์
update episodeเปลี่ยนรายละเอียดของตอน
remove episodeเอาตอนออกจากคลัง ไฟล์ยังคงอยู่
refresh libraryอ่านคลังอีกครั้ง
create account, change account password, delete account, account names, account logจัดการบัญชี

คำอธิบายแบบยาวที่ใส่ด้วยวิธีนี้จะเก็บไว้ในฐานข้อมูลของ TV Library Viewer และจะใส่กลับเข้าไปเมื่อ แอป TV ลืมคำอธิบายนั้น
