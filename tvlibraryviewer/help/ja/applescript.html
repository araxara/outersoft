AppleScript

TV Library Viewerはスクリプトで操作できます。たとえば、エピソードを読み込むスクリプトから使えます。詳しくは、スクリプトエディタでTV Library Viewerの用語説明を開いてください（ファイル › 用語説明を開く…）。

コマンド機能
add episodeビデオファイルを番組、シーズン、エピソード、タイトル、ジャンル、説明とともにTVアプリのライブラリに追加し（すでにある場合はそれを見つけ）、その永続IDを返します。
update episodeエピソードの詳細を変更します。
remove episodeエピソードをライブラリから削除します。ファイルはそのまま残ります。
refresh libraryライブラリを読み込み直します。
create account、change account password、delete account、account names、account logアカウントを管理します。

この方法で指定した詳しい説明はTV Library Viewerのデータベースに保存され、TVアプリから失われたときに元に戻されます。
