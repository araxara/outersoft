TV Library Viewerのデータベース

このMac上にあるTV Library Viewer独自のデータベースです。ライブラリを表示するすべてのデバイスと共有されます。

項目内容
作品情報AppleScriptで指定した詳しい説明と、各番組のキャスト（俳優の名前と役柄）。
翻訳アプリで設定された言語に翻訳されたエピソードのタイトルと説明。
キャストとスタッフ1人につき1枚の小さな写真と、TVmazeとTMDbにあるその人のページのアドレス。
アカウントと視聴アカウント、メインアカウント以外のすべてのアカウントの視聴状況、アカウントのログ。
データベースの構造と空き領域SQLite自体の記録と、再利用される領域。
最近の変更まだデータベースに統合されていない変更。統合はときどき自動的に行われます。

番組のキャストとスタッフは、このMacまたはいずれかのデバイスでその番組のページが初めて開かれたときに、TVmazeとTMDbで調べられます。人物の詳細は開くたびに取得されるので常に最新で、保存はされません。データベースファイルを見るには、Finderに表示をクリックします。

キャストとスタッフの詳細：TMDbのトークン

TVmazeは設定不要です。TMDb（The Movie Database）を使うと、監督や脚本家、TVmazeにない俳優、経歴が追加され、多くの場合あなたの言語で表示されます。TMDbには自分のトークンが必要です。TMDbはアカウントを持つ人なら誰にでも、個人的な非商用の利用のために無料でトークンを発行しています。TV Library Viewerにはトークンは付属していません。

  1. themoviedb.orgで無料のアカウントを作成し、サインインします。
  2. アカウントのアイコンをクリックし、Settingsを選択してから、APIをクリックします。
  3. APIキーをリクエストします。Developerを選択し、規約に同意して、用途を個人的な非商用の利用として説明します（例：「自分のテレビライブラリアプリでキャストと経歴を表示する」）。
  4. キーの準備ができたら、API Read Access Token（短いAPI Keyではなく、長いほう）をコピーします。
  5. ライブラリのあるMacでTV Library Viewer › 設定を選択し、ストレージをクリックして、TMDb API Read Access Tokenにペーストします。
  6. テストをクリックします。「TMDbはこのトークンを受け付けます。」と表示されれば使えます。

トークンはMacのキーチェーンに保存されます。トークンを使うのはライブラリのあるMacだけで、ほかのデバイスはそのMacからキャストと詳細を受け取ります。すでに調べた番組は、次にそのページが開かれたときにTMDbのキャストとスタッフが追加されます。新しいトークンをテストせずに設定を閉じた場合は、そのときにテストされ、TMDbが拒否すると通知されます。

注記：本製品はTMDB APIを使用していますが、TMDBによる承認または認定を受けたものではありません。

翻訳：Googleのキー

エピソードのタイトルと説明は、AppleのTranslationを使ってこのMac上で各デバイスの言語に無料で翻訳されます。ただし、ギリシャ語、チェコ語、ハンガリー語、ルーマニア語、ペルシャ語、ウルドゥー語、ベンガル語には翻訳できません。これらの言語には、自分のGoogle Cloud Translation APIキーを追加します。キーが必要なのはライブラリのあるMacだけで、ライブラリを表示するデバイスには必要ありません。毎月最初の50万文字までは無料で、各テキストが翻訳されるのは1回だけです。

  1. console.cloud.google.comにアクセスし、Googleアカウントでサインインします。
  2. プロジェクトを作成します。上部のプロジェクトメニューをクリックし、New Projectをクリックして、「TV Library Viewer」などの名前を付けます。
  3. 課金を有効にします。メニュー☰でBillingを選択し、請求先アカウントをリンクします。無料で使う場合でも、Googleは請求先アカウントを求めます。念のため、Budgets & alertsで1ドルなどの予算を追加しておきます。
  4. ☰ › APIs & Services › Libraryを選択し、Cloud Translation APIを検索して、Enableをクリックします。
  5. ☰ › APIs & Services › Credentialsを選択し、Create credentials › API keyを選んで、キー（「AIza」で始まります）をコピーします。
  6. 推奨：キーの名前をクリックし、API restrictionsでRestrict keyを選択して、Cloud Translation APIにチェックを入れ、Saveをクリックします。これで、キーは翻訳にしか使えなくなります。
  7. ライブラリのあるMacでTV Library Viewer › 設定を選択し、ストレージをクリックして、Google Cloud Translation APIキーにキーをペーストし、テストをクリックします。

キーはMacのキーチェーンに保管され、これら7つの言語にだけ使われます。キーは他人と共有しないでください。キーを使って翻訳されたものはすべて、あなたのGoogleアカウントに請求されます。
