کاسٹ اور عملے کی تفصیلات: ⁨TMDb⁩ ٹوکن

⁨TVmaze⁩ کو کسی سیٹ اپ کی ضرورت نہیں۔ ⁨TMDb⁩ (The Movie Database) ہدایت کار اور اسکرین رائٹرز، وہ اداکار جو ⁨TVmaze⁩ کے پاس نہیں، اور سوانح عمریاں شامل کرتا ہے، اکثر آپ کی زبان میں۔ اس کے لیے آپ کا اپنا ٹوکن درکار ہے: ⁨TMDb⁩ اکاؤنٹ رکھنے والے ہر شخص کو ذاتی، غیر تجارتی استعمال کے لیے مفت ٹوکن دیتا ہے۔ ⁨TV Library Viewer⁩ کے ساتھ کوئی ٹوکن نہیں آتا۔

  1. themoviedb.org پر ایک مفت اکاؤنٹ بنائیں، اور سائن ان کریں۔
  2. اپنے اکاؤنٹ کے آئیکن پر کلک کریں، ⁨Settings⁩ چنیں، پھر ⁨API⁩ پر کلک کریں۔
  3. API کلید کی درخواست کریں: ⁨Developer⁩ چنیں، شرائط قبول کریں، اور اپنے استعمال کو ذاتی اور غیر تجارتی بتائیں (مثلاً ”Show cast and biographies in my own TV library app“)۔
  4. جب کلید تیار ہو جائے، تو ⁨API Read Access Token⁩ کاپی کریں (لمبا والا، چھوٹی API Key نہیں)۔
  5. لائبریری والے Mac پر، ⁨TV Library Viewer⁩ › سیٹنگز چنیں، اسٹوریج پر کلک کریں، اور اسے ⁨TMDb⁩ ⁨API Read Access Token⁩ میں پیسٹ کریں۔
  6. جانچیں پر کلک کریں۔ ”⁨TMDb⁩ یہ ٹوکن قبول کرتا ہے“ کا مطلب ہے کہ یہ کام کرتا ہے۔

ٹوکن Mac کی کی چین میں رکھا جاتا ہے۔ اسے صرف لائبریری والا Mac استعمال کرتا ہے؛ آپ کی دوسری ڈیوائسز کاسٹ اور تفصیلات اسی Mac سے لیتی ہیں۔ جو شوز پہلے ڈھونڈے جا چکے ہیں انہیں ⁨TMDb⁩ کی کاسٹ اور عملہ اگلی بار ان کا صفحہ کھلنے پر ملتا ہے۔ اگر آپ نئے ٹوکن کی جانچ کیے بغیر سیٹنگز بند کر دیں، تو اس کی جانچ اسی وقت ہوتی ہے، اور اگر ⁨TMDb⁩ اسے رد کرے تو آپ کو بتایا جاتا ہے۔

نوٹ: یہ پروڈکٹ ⁨TMDB⁩ API استعمال کرتی ہے لیکن ⁨TMDB⁩ کی طرف سے اس کی توثیق یا تصدیق نہیں کی گئی۔

ترجمہ: ⁨Google⁩ کلید

اقساط کے عنوانات اور تفصیلات اس Mac پر ⁨Apple⁩ کے ترجمے سے، مفت، ہر ڈیوائس کی زبان میں ترجمہ کی جاتی ہیں۔ یہ یونانی، چیک، ہنگیرین، رومانیائی، فارسی، اردو یا بنگالی میں ترجمہ نہیں کر سکتا۔ ان زبانوں کے لیے اپنی ⁨Google Cloud Translation API⁩ کلید شامل کریں۔ اس کی ضرورت صرف لائبریری والے Mac کو ہے؛ اسے دیکھنے والی ڈیوائسز کو نہیں۔ ہر مہینے پہلے 500,000 حروف مفت ہیں، اور ہر متن کا ترجمہ صرف ایک بار ہوتا ہے۔

  1. ⁨console.cloud.google.com⁩ پر جائیں اور اپنے ⁨Google⁩ اکاؤنٹ سے سائن ان کریں۔
  2. ایک پروجیکٹ بنائیں: اوپر پروجیکٹ مینو پر کلک کریں، پھر ⁨New Project⁩ پر، اور اسے کوئی نام دیں، جیسے ”⁨TV Library Viewer⁩“۔
  3. بلنگ آن کریں: مینو ☰ میں ⁨Billing⁩ چنیں اور ایک بلنگ اکاؤنٹ منسلک کریں۔ ⁨Google⁩ مفت استعمال کے لیے بھی اس کا تقاضا کرتا ہے۔ احتیاطاً ⁨Budgets & alerts⁩ میں کوئی بجٹ شامل کریں، جیسے 1 ڈالر۔
  4. ☰ › ⁨APIs & Services › Library⁩ چنیں، ⁨Cloud Translation API⁩ تلاش کریں، اور ⁨Enable⁩ پر کلک کریں۔
  5. ☰ › ⁨APIs & Services › Credentials⁩ چنیں، پھر ⁨Create credentials › API key⁩، اور کلید کاپی کریں (یہ ”⁨AIza⁩“ سے شروع ہوتی ہے)۔
  6. تجویز: کلید کے نام پر کلک کریں، ⁨API restrictions⁩ کے تحت ⁨Restrict key⁩ چنیں، ⁨Cloud Translation API⁩ پر نشان لگائیں، اور ⁨Save⁩ پر کلک کریں، تاکہ کلید صرف ترجمے کے لیے کام کرے۔
  7. لائبریری والے Mac پر، ⁨TV Library Viewer⁩ › سیٹنگز چنیں، اسٹوریج پر کلک کریں، کلید کو ⁨Google Cloud Translation API⁩ کلید میں پیسٹ کریں، اور جانچیں پر کلک کریں۔

کلید Mac کی کی چین میں رکھی جاتی ہے اور صرف انہی سات زبانوں کے لیے استعمال ہوتی ہے۔ اسے کسی کو نہ دیں: اس سے ترجمہ ہونے والی ہر چیز کا بل آپ کے ⁨Google⁩ اکاؤنٹ پر آتا ہے۔
